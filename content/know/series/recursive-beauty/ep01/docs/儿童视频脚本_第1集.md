## 一、本集定位

口播里那句"我们做了一套小学低年级的数学启蒙小动画，从一道找规律题破开"，本集就是它。把配套 A 的"递推"知识核，翻成孩子能看、能动手推的动画。家长学配套 A，孩子看本集，亲子共学闭环。

---

## 二、分镜脚本（含互动节点）

| 时间      | 画面                                                         | 字幕/旁白              | 互动                         |
| ------- | ---------------------------------------------------------- | ------------------ | -------------------------- |
| 0–8s    | 米白底，一只小兔子蹦出，数字 1 轻轻落下                                      | 旁白：今天玩一个"数数游戏"     | 无                          |
| 8–20s   | 数字依次跳出：1, 1, 2, 3, 5, 8，每个配一朵花/一只兔，跳动入场                    | 旁白：1，1，2，3，5，8……   | 无                          |
| 20–30s  | 8 之后一个大问号闪动，朱砂圈住问号                                         | 旁白：下一个是谁？          | **暂停点①**：画面定格，提示"想一想，再点一下" |
| 30–38s  | 孩子点击后，5 和 8 亮起，相加飞出 13                                     | 旁白：5 加 8，是 13      | 点击触发                       |
| 38–55s  | 递推演示：两个格子（前项+前前项）合并生成下一项，连续演示 8+13=21、13+21=34，台阶/花瓣一对对长出来 | 旁白：前一个，加再前一个，就是下一个 | 无                          |
| 55–75s  | 兔子繁殖小故事：一对兔子，每月生一对，数量 1,1,2,3,5,8… 动画配对                    | 旁白：这串数，兔子也知道       | 无                          |
| 75–90s  | 回看数列，朱砂指针扫过，问号变句号                                          | 旁白：规律不是玄学，是往前推     | 无                          |
| 90–110s | 小兔子看着数列，问号变成句号，自己蹦出"13"                              | 旁白：原来知道一个东西怎么长，比知道它是什么，好玩多了 | 无                          |

**互动设计（核心）**
- 暂停点①为 mandatory 互动：不揭答案，等孩子操作。
- 选项设计（点击揭示前可给三选一）：11 / 12 / **13**，选错给温柔提示"再看看前两个加起来？"，选对播放生成动画。
- 进阶互动（可二期）：让孩子自己输"下一个"，答对解锁下一集预告。

## 三、视觉与制作说明

- **底色/字**：米白纸底 #F5F0E8，墨色字 #2B2B2B，朱砂 #C0392B 仅圈问号/指针，同屏不现第二处红。
- **字体**：大而精，儿童向圆体但克制，不发光不渐变。
- **动效**：数字跳动入场、合并飞出用轻缓位移，禁弹跳缓动/扫光/3D 翻转。
- **工具链（已定）**：HTML / CSS / SVG / Canvas 直接渲染（见 `代码动画\第1集_递推之美.html`）。可屏幕录制为视频，也可浏览器直接打开独立访问（学习机/电视/电脑）。互动用原生 JS 事件（点击揭示、暂停点），无外部依赖。
- **音频**：旁白 AI 配音（儿童向温和音色），轻背景音（钢琴单音，不抢人声）。

## 四、与配套 A 的呼应

| 配套 A（家长听） | 本集（孩子看） |
|------------------|----------------|
| 讲递推 a(n)=a(n-1)+a(n-2) | 用"前两个加起来"动画化 |
| 破题三层（递推/通项/归纳） | 本集只做递推第一层，留阶可深 |
| 亲子话术：问"你发现什么规律" | 暂停点让孩子自己发现 |

家长听懂了"递推"，孩子看动画推出来了——同一个规律，两代人各得其所。
