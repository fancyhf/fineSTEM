## 4. 前端配置

- **proxy**（转发到 `http://localhost:3200`）：

## 6. ZeroClaw AI 底座

### 6.1 架构角色

ZeroClaw 是 **AI Agent Runtime + Gateway + Provider 抽象层**，承担：
- Agent Loop（对话 + 工具调用主循环）
- LLM Provider 管理（DeepSeek 主，可加 GLM/Qwen fallback）
- MCP 工具调度（spawn fineSTEM MCP server，调 `finestem__*` 工具）
- WebSocket Gateway（前端直连 `ws://127.0.0.1:42617/ws/chat`）
- Memory（跨 session 记忆）

### 6.2 关键配置（config.toml）

| 配置 | 值 | 说明 |
|------|-----|------|
| `providers.models.deepseek.default.model` | deepseek-v4-pro | 主模型 |
| `providers.models.deepseek.default.max_tokens` | **65536** | 单次输出上限（Q-023 修复，防截断） |
| `agents.assistant.model_provider` | deepseek.default | Agent 用 DeepSeek |
| `agents.assistant.mcp_bundles` | ["pbl"] | 加载 fineSTEM MCP 工具 |
| `runtime_profiles.default.max_tool_iterations` | 100 | 工具调用循环上限 |
| `risk_profiles.standard.auto_approve` | finestem__* 等 | PBL 工具自动放行（不弹审批） |

### 6.3 前端直连架构（2026-07-19 重大变更）

前端聊天链路从后端 FastAPI `/api/v1/agent/ws` **切换为直连 ZeroClaw** `/ws/chat`：
- context 在前端 `buildOutgoingMessage` 构建（project_id / stage / teaching_mode / student_profile）
- 后端 orchestrator.py / agent.py / chat.py **退役为死代码**
- AI Provider / Tool Loop / Memory / Security 全部由 ZeroClaw 承担

详见 `.trae/documents/技术与架构/ZeroClaw_技术知识库_v1.0.0.md`。
