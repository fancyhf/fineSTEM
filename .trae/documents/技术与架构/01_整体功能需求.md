## 1. 产品定位

**fineSTEM 是面向 12-18 岁青少年的 STEM 研学助手平台**——在线体验、AI 引导、过程驱动，从兴趣启蒙到成果展示一站式。

核心差异：**不是"编程平台"**。传统平台教"怎么写代码"，fineSTEM 教"怎么完成一个项目"（代码只是工具之一）。

单一用户形态：**学生**。按参与深度分三级（逐步升级路径，非静态分层）：
- **Level 1 体验者**：先看见、先试玩、先理解
- **Level 2 创作者**：我也做一个、做出自己的版本
- **Level 3 深度开发者**：完整 PBL 流程，做完整项目

核心转化链路：**看见 → 体验 → 理解 → 我也做 → 变成我的 → 完善 → 成果 → 展示 → 激励他人**

## 2. 四大功能模块

| 模块 | 含义 | 路由入口 |

## 3. 核心功能需求清单

### 3.1 探索中心

| 功能 | 需求 | 优先级 |
|------|------|--------|
| **Demo 墙** | 每个 Demo 卡 4 动作：先试玩 / 看拆解 / 我也做一个 / 保存 | P0 |
| **Fork 最小可改版** | 点"我也做一个"→ 获得高质量 fork 模板（保留核心逻辑、去掉复杂功能、标记"可改点"、附带 3 个改动建议、预填默认目标模板） | P0 |
| **灵感墙** | 展示成果档案卡（不直接展示代码），支持"我也能做"回流 fork | P1 |
| **Demo 详情** | 拆解步骤、技术栈说明、在线试玩 | P1 |

### 3.2 AI 工作台（Create 页）

| 功能 | 需求 | 优先级 |
|------|------|--------|
| **场景化 AI 入口** | 4 个场景：问问题 / 解释代码 / 开始项目 / 写报告（场景优先，自动注入上下文） | P0 |
| **AI 对话流** | 与 ZeroClaw AI 导师实时对话，流式输出，支持思考链展示 | P0 |
| **结构化提问** | AI 调 `ask_question` 工具生成可点击选项卡（非纯文字选项），前端渲染卡片 | P0 |
| **在线代码编辑器** | Monaco Editor，代码写入/运行/预览，HTML 直接预览，Python/JS 沙箱运行 | P0 |
| **代码生成与写入** | AI 调 `project_code_writer` 写入编辑器，多文件支持，自动预览 | P0 |
| **"修复错误"按钮** | 代码运行报错时，点按钮自动把错误发给 AI 请求修复 | P1 |
| **续接生成** | 输出截断时显示"继续生成"按钮，支持自动续接 + 手动续接 | P0 |

### 3.3 研学流程（双项目模式）

#### 3.3.1 轻项目模式（默认入口，30 分钟~2 小时）

| 功能 | 需求 |
|------|------|
| **3 步流程** | step_1 想法与方向 → step_2 设计与实现 → step_3 展示与反思 |
| **产出** | 轻量成果档案卡 |
| **升级** | 随时可升级为标准模式，已填内容/代码/截图继承，不重开 |

#### 3.3.2 标准研学模式（6~12 小时+）

| 功能 | 需求 | 优先级 |
|------|------|--------|
| **9 阶段 PBL 流程** | 脑爆 → 开题 → 范围 → 轨道 → 设计 → 计划 → 编码 → 验收（详见 §4） | P0 |
| **阶段门禁** | 每阶段必须完成必产出工件才能推进（后端硬门禁 + 前端检测） | P0 |
| **教学模式选择** | stage_07 必须先选教学模式（引导/演示/动手/讲解）才能写代码 | P0 |
| **研学工单** | 每阶段展示当前步/产出/最小完成标准/AI 可怎么帮 | P1 |
| **研学文档** | 开题/技术/结题报告，AI 辅助生成结构与引导（不代写），导出 PDF/DOCX | P1 |
| **自动证据采集** | 平台自动（阶段变更/AI 对话摘要）> 代码版本 > 截图 > 手动上传 | P1 |

#### 3.3.3 成果档案卡（核心展示单元）

| 字段 | 说明 |
|------|------|
| 项目名称、一句话描述 | 基础信息 |
| 解决了什么、用了什么方法 | 核心内容 |
| 截图或演示、反思 | 展示与总结 |
| AI 总结能力标签 | 自动生成 |
| 项目模式、完成时间 | 元数据 |

- 默认私有；可生成分享链接（`/share/:token` 公开查看）；可发布灵感墙；可撤回

## 4. 标准 9 阶段 PBL 流程

> 这是 fineSTEM 的核心教学引擎。AI 导师按阶段引导学生，每阶段有必产出工件和门禁。

| 阶段 key | 名称 | 必产出工件 | 门禁 |
|----------|------|-----------|------|
| stage_00_bootstrap | 初始化 | 无（项目目录 + SKILL_STATE） | — |
| stage_01_brainstorm | 脑爆选题 | brainstorm | — |
| stage_02_brief | 开题立项 | project_brief | — |
| stage_03_constraints | 范围裁剪 | constraints | — |
| stage_04_track | 技术轨道选择 | track_plan | **硬门禁：JSON 含 track/tech_stack** |
| stage_05_design | 设计蓝图 | design | — |
| stage_06_step_plan | 分步计划 | step_plan | — |
| stage_07_execute | 执行开发 | dev_log | **硬门禁：须先选教学模式** |
| stage_08_evaluate | 验收展示 | — | — |

**推进规则**：只能向前，不能回退。门禁失败必须补全 missing 清单再推进。

**代码锁**：仅 stage_05/07/08 允许写代码（调 `project_code_writer`），其他阶段拒绝。

## 5. MVP 范围

**核心验证闭环**：学生进入 → 看 Demo → 点"我也做一个" → 获得高质量 fork 模板 → AI 引导完成轻项目 → 生成成果档案卡 → 复制分享链接

**成功判据 4 指标**：Demo→fork 点击率 / fork→轻项目完成率 / 成果档案卡生成率 / 成果分享率
