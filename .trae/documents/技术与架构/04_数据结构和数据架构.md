## 1. 数据库概述

- **引擎**：SQLite（WAL 模式，`synchronous=NORMAL`，`foreign_keys=ON`）
- **路径**：`D:/data/finestem/finestem.db`（`DATABASE_URL` 可配）
- **ORM**：SQLAlchemy 2.0（`Mapped` / `mapped_column` 风格）
- **迁移**：Alembic（`app/db/migrations/`）
- **模型文件**：`apps/backend/app/db/models.py`（⚠️ `app/models/` 目录为空，勿引用）

## 2. 数据表清单

### 通用审计 Mixin（AuditMixin）

多数表继承，含字段：`created_at`、`created_by`、`updated_at`（onupdate 自动刷新）、`updated_by`、`deleted_at`、`deleted_by`、`is_deleted`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String(64) PK | 用户 ID |
| name | String | 昵称 |
| email | String unique index | 邮箱 |

| level | Integer default=1 | 学生等级（1/2/3） |

### 2.2 projects — 研学项目（核心）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String(64) PK | 项目 ID |
| author_id | String index | 所属用户 |
| name | String | 项目名（创建时=首条消息截断，AI 确认后自愈同步） |

| from_demo_id | String nullable | Fork 来源 Demo |
| **initial_data** | **Text default={}** | **内嵌 workspace（JSON，见 §3.2）** |

### 2.3 skill_states — SKILL_STATE 状态机（1:1 project）

| 字段 | 类型 | 说明 |
|------|------|------|
| **project_id** | **String(64) PK** | 项目 ID（外键 projects.id） |
| version | String default=1.0.0 | 状态机版本 |
| mode | String | light/standard |
| current_stage | String | 当前阶段（12 枚举值） |
| light_step | String(8) nullable | 1/2/3（仅 light） |
| **stages** | **Text default={}** | Dict[stage_key → {status, started_at, completed_at, data}] |
| **metadata** | **Text default={}** | Dict（teaching_mode、teachingModeConfirmed、student_profile、name_manually_overridden） |
| light_to_standard_mapping | Text nullable | 升级映射记录 |
| stage_history | Text default=[] | List[Dict] |
| **light_step_data** | **Text default={}** | 轻项目步骤数据（Dict） |
| **standard_step_data** | **Text default={}** | 标准阶段工件数据（Dict） |

**stages.status 合法值（仅 4 态）**：`locked` / `active` / `completed` / `skipped`
> ⚠️ Q-014 根因：曾存 `in_progress`/`not_started` 导致 500，已加 4 层规范化兜底。

**current_stage 合法值（12 个）**：
- light：`step_1` / `step_2` / `step_3`
- standard：`stage_00_bootstrap` ~ `stage_08_evaluate`（9 个）

## 3. 关键嵌套数据结构

### 3.1 standard_step_data（标准阶段工件）

JSON Dict，key 为工件 blob_key，value 为工件内容（JSON 字符串或 markdown）：

```json
{
  "brainstorm_content": "...(markdown)",
  "brief_content": "{\"project_name\":\"...\", \"title\":\"...\", ...}",
  "track_plan": "{\"track\":\"web\", \"tech_stack\":[\"HTML\",\"JS\"]}",
  "design": "...",
  "step_plan": "{\"steps\":[...]}",
  "dev_log": "...(markdown)"
}
```

各阶段工件结构（Stage01-08Data）：
- **brainstorm**：ideas / top_picks / selected_idea
- **brief**：标题 / 问题 / 成功标准 / 风险
- **constraints**：must / nice / wont
- **track**：8 轨道枚举（web/web_app/game_dev/ai_ml/data_viz/creative_coding/kaggle/hardware）
- **design**：UI / 组件 / 验收
- **step_plan**：steps[]（每步含 run/check/rollback）
- **execute**：milestones / dev_log
- **evaluate**：验收结果 / 反思 / achievement_card_id

### 3.2 workspace（内嵌于 projects.initial_data）

> ⚠️ workspace 不是独立表，是 `projects.initial_data` 的 JSON 子对象，通过 `project_repo.py:_extract_workspace` 提取。

```json
{
  "code": "...(完整源代码)",
  "language": "html",
  "filename": "index.html",
  "chat_messages": [{"role":"user","content":"..."}, ...],
  "preview_html": "...",
  "saved_at": "2026-07-29T...",
  "chat_saved_at": "2026-07-29T...",
  "files": [{"name":"index.html","language":"html","content":"...","is_main":true}],
  "code_history": ["...(旧版本快照，最近5版)"]
}
```

**保存保护**（`save_project_workspace`）：
1. MVP 模板拦截（指纹匹配如 "fineSTEM MVP"，静默拒绝）
2. 历史快照 + 可疑覆盖检测（新 code < 旧 10% 且 language 变化 → 告警）

### 3.3 metadata（skill_states.metadata 列）

JSON Dict：

```json
{
  "teachingMode": "guided",
  "teachingModeConfirmed": true,
  "student_profile": {"年级": ["初中"], "兴趣": ["游戏","动画"]},
  "name_manually_overridden": true
}
```

## 4. 数据关系图

```
users (1) ──< projects (N) ──1:1── skill_states (project_id 为 PK)
                      │                     ├── stages (JSON, status 4 态)
                      │                     ├── metadata (teaching_mode, student_profile)
                      │                     ├── light_step_data / standard_step_data
                      │                     └── stage_history
                      ├──1:1── achievement_cards (project_id unique)
                      ├──< evidence (N, 含复合索引)
                      ├──1:1── project_capability_tags
                      └── initial_data (Text) ← 内嵌 workspace
                                  ├── code / files / chat_messages
                                  └── code_history (最近5版)
demos (1) ──fork──< projects (from_demo_id)
```

## 5. 已知数据问题与防御（历史教训）

| 问题 | 根因 | 防御 |
|------|------|------|
| **Q-014** stages 非法状态值致 500 | LLM 写入 `in_progress`/`not_started`（合法仅 4 态） | 4 层规范化兜底（读取/增量写/全量写入口） |
| **Q-015** light_step_data 多层 JSON 编码 | SkillStateWriterTool 无解码防御，字符串被反复 json.dumps | `json_loads` 多层自动解码 + 写入前解包 |
| **Q-016** 对话不落库 | projectId 延迟创建 + 无离开强制保存 | 项目创建后补存 + visibilitychange/pagehide 强制保存 |
| **Q-022** 项目名不同步 | AI 确认名只存 skill_state，不回写 projects.name | `_sync_project_name_from_skill_state` 自愈 + `name_manually_overridden` 标志防覆盖 |

> 详见 `.trae/documents/问题清单_长期维护.md`（Q-014~Q-023）。
