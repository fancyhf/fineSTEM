## 2. 目录结构（服务器）

```text
/opt/finestem/
├── app/                        # FastAPI 后端运行目录（扁平布局，非 git 仓库）
│   ├── main.py                 # uvicorn 入口（systemd WorkingDirectory）
│   ├── .env                    # 环境变量（含 KNOW_CONTENT_DIR）
│   └── app/                    # 后端包
│       ├── api/                # 路由（含 know.py）
│       ├── services/           # 服务（含 know_content.py）
│       ├── schemas/            # Schema（含 know.py）
│       └── core/config.py      # 配置（含 KNOW_CONTENT_DIR 字段）
├── repo/                       # GitHub 仓库浅克隆（代码来源，350MB）
│   ├── apps/backend/           # ← 对应运行目录 /opt/finestem/app
│   ├── apps/know/              # Know 前端源码（在此 npm run build）
│   └── content/know/           # Know 内容库（content-as-code）
├── frontend/dist/              # 主站前端产物（Nginx root）
├── know/dist/                  # Know 前端产物（Nginx root）
├── content/know/               # Know 内容库运行副本（nginx /content/ 指向）
├── data/                       # 业务数据 (SQLite + 文件)
│   ├── finestem.db             # 主数据库
│   ├── uploads/                # 用户上传
│   ├── generated/              # 生成内容 (covers 等)
│   ├── projects/              # 项目文件
│   └── demos/                  # Demo 截图
└── venv/                       # 后端虚拟环境

/opt/zeroclaw/
├── bin/zeroclaw                # v0.8.4 二进制
└── config/config.toml         # AI 配置 (单处)

/etc/nginx/sites-enabled/finestem.conf   # 主站 Nginx 配置
/etc/nginx/sites-enabled/know.conf        # Know 频道 Nginx 配置
/etc/letsencrypt/live/wostemstudio.site/      # 主站 SSL 证书
/etc/letsencrypt/live/know.wostemstudio.site/ # Know SSL 证书
```

> **注意**：后端运行目录是 `/opt/finestem/app`（扁平布局），而仓库里是 `apps/backend/`。
> 两者是同构的（`/opt/finestem/app` == 仓库 `apps/backend`），更新代码时按此对应关系复制。
> `/opt/finestem/repo` 仅作为**代码来源**（git pull 取文件），不直接运行。

## 3. Nginx 配置要点

完整配置见 `/etc/nginx/sites-enabled/finestem.conf`：

- `:80` → 301 跳转 HTTPS
- `:443` → Let's Encrypt 终结
- `/` → 前端静态 (`/opt/finestem/frontend/dist`)，SPA fallback
- `/api/` → `proxy_pass http://127.0.0.1:8001`（**保留 `/api/` 前缀**）
- `/ws/chat` → `proxy_pass http://127.0.0.1:42617/ws/chat`（WebSocket，Upgrade 头）
- `/static/uploads/` → `alias /opt/finestem/data/uploads/`（图片静态服务）
- `/static/generated/` → `alias /opt/finestem/data/generated/`

> ⚠️ 图片 404 修复记录：初版 Nginx 漏配 `/static/` 映射，导致上传图片全部 404。已补充 `alias` 规则并 `nginx -t && systemctl reload nginx`。

## 4. 部署流程（可复现）

### 4.1 系统初始化

```bash
apt update && apt install -y nginx python3.12 python3.12-venv nodejs npm git curl
ufw allow 22,80,443/tcp && ufw enable
```

### 4.2 部署 ZeroClaw

```bash
# 下载 Linux x86_64 二进制到 /opt/zeroclaw/bin/zeroclaw
# 写 /opt/zeroclaw/config/config.toml (见 §6)
# systemd: /etc/systemd/system/zeroclaw.service
systemctl daemon-reload && systemctl enable --now zeroclaw
```

### 4.3 部署后端

```bash
git clone <repo> /opt/finestem/backend
cd /opt/finestem/backend && python3.12 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
# 写 .env (见 §5)
systemctl enable --now finestem-backend
```

### 4.4 部署前端

```bash
cd /opt/finestem/backend && npm install && npm run build
# 产物输出到 /opt/finestem/frontend/dist (或 cp 到 Nginx root)
systemctl reload nginx
```

### 4.5 SSL

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d wostemstudio.site -d www.wostemstudio.site
# 自动续签: systemd timer certbot.timer (已启用)
```

## 5. 环境变量（后端 .env）

位置：`/opt/finestem/backend/.env`

```ini
DATABASE_URL=sqlite:////opt/finestem/data/finestem.db
VITE_ZC_TOKEN=<ZeroClaw Bearer Token>
VITE_ZC_WS_URL=wss://wostemstudio.site/ws/chat
CORS_ORIGINS=https://wostemstudio.site
```

> 密钥明文存于服务器 `.env`，不入库。开发环境同理收敛到 `H:\dev-env\zeroclaw\config\config.toml` 单处。

## 6. LLM Key 配置（单处，高峰切换）

**配置位置（唯一）**：`/opt/zeroclaw/config/config.toml`

```toml
[agents.assistant]        # 非高峰 → DeepSeek
provider = "deepseek"
alias = "deepseek.default"

[agents.assistant_qwen]   # 高峰 → 百炼 qwen
provider = "qwen"
alias = "qwen.default"

[models.deepseek.default]
api_key = "enc2:..."      # 已加密存储

[models.qwen.default]
api_key = "enc2:..."      # 已加密存储
```

**切换逻辑**：前端 `getZcAgentAlias()` 根据北京时段判断：
- 高峰（9-12, 14-18）→ `assistant_qwen` → 百炼 qwen
- 非高峰 → `assistant` → DeepSeek

> 冗余 LLM Key（fangzhou/bailian/glm 等）已清理，仅保留 deepseek + qwen 两处。

## 7. 数据同步（开发 → 生产）

```bash
# 1. 停服务
systemctl stop finestem-backend zeroclaw
# 2. 上传 D:\data\finestem 到服务器 (deploy_project_preparation 工具)
# 3. 同步业务文件,排除 backups/ test_*/ *.bak
cp finestem.db /opt/finestem/data/
cp -r uploads generated projects demos /opt/finestem/data/
# 4. 清 WAL/SHM
rm -f /opt/finestem/data/finestem.db-shm /opt/finestem/data/finestem.db-wal
# 5. 重启
systemctl start finestem-backend zeroclaw
```

## 10. Know 子系统（内容节目频道）

> 上线日期：2026-08-30 · 新增成本 ¥0（复用同机、同后端进程、Let's Encrypt 免费证书）

### 10.1 概览

| 项 | 值 |
|----|-----|
| 访问地址 | https://know.wostemstudio.site |
| 定位 | 内容节目频道「与孩子对话」，只读公开站点 |
| 前端 | /opt/finestem/know/dist（仓库 apps/know 构建） |
| 后端 | 复用 finestem-backend，路由 /api/v1/know/*（app/api/know.py） |
| 内容库 | /opt/finestem/content/know（nginx /content/ 静态服务） |
| SSL | 独立证书 /etc/letsencrypt/live/know.wostemstudio.site/（2026-11-28 到期） |
| 数据库 | 不落库，content-as-code（内容在 git 仓库 content/know） |

### 10.2 关键环境变量

`/opt/finestem/app/.env`：

```ini
KNOW_CONTENT_DIR=/opt/finestem/content/know
CORS_ALLOW_ORIGINS=["https://wostemstudio.site","https://know.wostemstudio.site"]
```

> `KNOW_CONTENT_DIR` 必须显式配置：代码内默认回退用 `Path(__file__).parents[N]` 上溯，
> 而服务器是扁平布局（main.py 在 /opt/finestem/app/），上溯层级与本地 monorepo 不同，
> 不加此变量会指向错误目录并静默返回空数据。

### 10.3 Nginx 要点（/etc/nginx/sites-enabled/know.conf）

- `root /opt/finestem/know/dist`
- `location /api/` → `proxy_pass http://127.0.0.1:8001`（**保留 /api/ 前缀**）
- `location /content/` → `alias /opt/finestem/content/know/`
- `location /` → SPA fallback
- 与主站 finestem.conf 完全独立，**互不影响**

### 10.4 发布新内容流程

1. 内容生产后由 Agent 搬运入库到仓库 `content/know/series/<系列>/<集>/`
2. `npm run validate:content` 零错误
3. `git commit` + `git push`（服务器只能从 GitHub 获取）
4. 服务器：`cd /opt/finestem/repo && git pull --ff-only`
5. 同步内容：`cp -r /opt/finestem/repo/content/know/* /opt/finestem/content/know/`
6. **无需重启后端**（后端按文件指纹自动重扫）

### 10.6 排障

| 症状 | 检查 |
|------|------|
| 首页有壳无数据 | `KNOW_CONTENT_DIR` 是否指向真实目录；目录缺失时接口静默返回空 |
| /content/ 404 | nginx alias 路径；`ls /opt/finestem/content/know` |
| 构建报 TS2307 缺模块 | 仓库缺文件，确认本地已 `git push`（曾因 .gitignore 的 `lib/` 规则误伤 `apps/know/src/lib/`） |
| 证书告警 | `certbot certificates` 应包含 know.wostemstudio.site |
