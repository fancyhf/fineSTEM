## 3. Nginx 配置要点

完整配置见 `/etc/nginx/sites-enabled/finestem.conf`：

- `:80` → 301 跳转 HTTPS
- `:443` → Let's Encrypt 终结
- `/` → 前端静态 (`/opt/finestem/frontend/dist`)，SPA fallback
- `/api/` → `proxy_pass http://127.0.0.1:8001`（**保留 `/api/` 前缀**）
- `/ws/chat` → `proxy_pass http://127.0.0.1:42617/ws/chat`（WebSocket，Upgrade 头）
- `/static/uploads/` → `alias /opt/finestem/data/uploads/`（图片静态服务）
- `/static/generated/` → `alias /opt/finestem/data/generated/`

> ⚠️ 图片 404 修复记录：初版 Nginx 漏配 `/static/` 映射，导致上传图片全部 404。已补充 `alias` 规则并 `nginx -t && systemctl reload nginx`。

## 4. 部署流程（可复现）

### 4.1 系统初始化

```bash
apt update && apt install -y nginx python3.12 python3.12-venv nodejs npm git curl
ufw allow 22,80,443/tcp && ufw enable
```

### 4.2 部署 ZeroClaw

```bash
# 下载 Linux x86_64 二进制到 /opt/zeroclaw/bin/zeroclaw
# 写 /opt/zeroclaw/config/config.toml (见 §6)
# systemd: /etc/systemd/system/zeroclaw.service
systemctl daemon-reload && systemctl enable --now zeroclaw
```

### 4.3 部署后端

```bash
git clone <repo> /opt/finestem/backend
cd /opt/finestem/backend && python3.12 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
# 写 .env (见 §5)
systemctl enable --now finestem-backend
```

### 4.4 部署前端

```bash
cd /opt/finestem/backend && npm install && npm run build
# 产物输出到 /opt/finestem/frontend/dist (或 cp 到 Nginx root)
systemctl reload nginx
```

### 4.5 SSL

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d wostemstudio.site -d www.wostemstudio.site
# 自动续签: systemd timer certbot.timer (已启用)
```

## 5. 环境变量（后端 .env）

位置：`/opt/finestem/backend/.env`

```ini
DATABASE_URL=sqlite:////opt/finestem/data/finestem.db
VITE_ZC_TOKEN=<ZeroClaw Bearer Token>
VITE_ZC_WS_URL=wss://wostemstudio.site/ws/chat
CORS_ORIGINS=https://wostemstudio.site
```

> 密钥明文存于服务器 `.env`，不入库。开发环境同理收敛到 `H:\dev-env\zeroclaw\config\config.toml` 单处。

## 6. LLM Key 配置（单处，高峰切换）

**配置位置（唯一）**：`/opt/zeroclaw/config/config.toml`

```toml
[agents.assistant]        # 非高峰 → DeepSeek
provider = "deepseek"
alias = "deepseek.default"

[agents.assistant_qwen]   # 高峰 → 百炼 qwen
provider = "qwen"
alias = "qwen.default"

[models.deepseek.default]
api_key = "enc2:..."      # 已加密存储

[models.qwen.default]
api_key = "enc2:..."      # 已加密存储
```

**切换逻辑**：前端 `getZcAgentAlias()` 根据北京时段判断：
- 高峰（9-12, 14-18）→ `assistant_qwen` → 百炼 qwen
- 非高峰 → `assistant` → DeepSeek

> 冗余 LLM Key（fangzhou/bailian/glm 等）已清理，仅保留 deepseek + qwen 两处。

## 7. 数据同步（开发 → 生产）

```bash
# 1. 停服务
systemctl stop finestem-backend zeroclaw
# 2. 上传 D:\data\finestem 到服务器 (deploy_project_preparation 工具)
# 3. 同步业务文件,排除 backups/ test_*/ *.bak
cp finestem.db /opt/finestem/data/
cp -r uploads generated projects demos /opt/finestem/data/
# 4. 清 WAL/SHM
rm -f /opt/finestem/data/finestem.db-shm /opt/finestem/data/finestem.db-wal
# 5. 重启
systemctl start finestem-backend zeroclaw
```
