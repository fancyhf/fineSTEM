## 1. 项目顶层结构

```
fineSTEM/
├── apps/
│   ├── frontend/          # React 前端（端口 5184）
│   │   └── src/
│   │       ├── pages/     # 17 个页面
│   │       ├── components/ # UI 组件
│   │       ├── hooks/     # 核心 Hook（useStreamingChat）
│   │       ├── services/  # API 客户端
│   │       ├── lib/       # 工具库（questionParser）
│   │       └── contexts/  # AuthContext
│   ├── backend/           # FastAPI 后端（端口 3200）
│   │   └── app/
│   │       ├── api/       # 15 个路由模块
│   │       ├── services/  # 核心服务（tools/pbl_engine/question_verifier）
│   │       ├── mcp_server/ # MCP 工具服务（stdio，供 ZeroClaw 调用）
│   │       ├── schemas/   # Pydantic 模型
│   │       ├── db/        # 数据库（models/repositories）
│   │       └── core/      # 配置/工具
│   └── public-web/        # 旧 MVP（docker-compose 用，非主开发栈）
├── .trae/
│   ├── skills/stem-pbl-guide/SKILL.md  # PBL 导师核心规范
│   ├── documents/          # 产品/技术文档
│   └── rules/             # 项目规范
└── H:\dev-env\zeroclaw\   # ZeroClaw AI 底座（Rust 二进制，端口 42617）
```

## 2. AI 主链路（核心架构）

```
前端 useStreamingChat.ts ──WebSocket──▶ ZeroClaw daemon (42617)
                                          │ Agent Loop + DeepSeek LLM
                                          │ MCP stdio
                                          ▼
                                   fineSTEM MCP server
                                   (mcp_server/server.py)
                                          │ tool.execute()
                                          ▼
                                   services/tools.py（15 个 PBL 工具）
                                          │
                                          ▼
                                   services/pbl_engine.py（门禁推进）
                                          │
                                          ▼
                                   db/repositories（SQLite）
```

> ⚠️ `apps/backend/app/services/orchestrator.py` 是 **DEPRECATED 死代码**，不在主链路。AI 编排由 ZeroClaw 承担。

| storage_service.py | 文件存储抽象 |

| ⚠️ orchestrator.py | **DEPRECATED**（168KB 死代码，非主链路） |

### 4.3 MCP Server（mcp_server/server.py）

- 协议：MCP 1.0 stdio（JSON-RPC 2.0）
- 把 `tools.py` 的 `TOOL_REGISTRY` 转 MCP tool spec
- ZeroClaw daemon spawn 本进程，工具名透传为 `finestem__<tool>`

### 4.4 15 个 PBL 工具（tools.py TOOL_REGISTRY）

| 工具名 | 职责 |
|--------|------|
| skill_state_reader | 读项目状态/学生画像/工件 |
| skill_state_writer | 写 metadata（教学模式等） |
| stage_advancer | 带门禁的阶段推进 |
| artifact_reader | 读阶段工件 |
| artifact_writer | 写阶段工件 |
| **ask_question** | 生成结构化问题选项卡 |
| **project_code_writer** | 写项目代码到编辑器（含阶段锁） |
| project_creator | 创建项目 |
| code_runner | 运行代码 |
| evidence_saver | 保存证据 |
| resource_searcher | 资源检索 |
| achievement_card | 生成成果档案卡 |
| project_memory_store | 项目记忆存储 |
| project_memory_recall | 项目记忆召回 |
| sop_state_sync | SOP 状态同步 |

## 5. AI 导师规范（stem-pbl-guide SKILL.md）

定义 AI 导师的行为约束（9 阶段流程、教学模式、门禁规则、防截断、防失忆）。ZeroClaw 加载此 Skill 作为 system prompt 补充。同步位置：
- `.trae/skills/stem-pbl-guide/SKILL.md`（源）
- `H:\dev-env\zeroclaw\config\agents\assistant\workspace\skills\stem-pbl-guide\SKILL.md`（daemon 副本）

## 6. 模块间关键依赖

- **Create.tsx** → `useStreamingChat`（WS 对话）+ `projectsApi`（CRUD）+ `questionParser`（卡片解析）
- **useStreamingChat** → ZeroClaw WS（42617）→ MCP → `tools.py`
- **tools.py** → `pbl_engine.py`（门禁）→ `repositories`（DB）
- **projects.py API** → `_build_workspace_payload`（含 Q-022 项目名自愈、workspace 提取）
