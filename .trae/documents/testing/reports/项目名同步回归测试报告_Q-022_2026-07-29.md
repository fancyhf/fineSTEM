### 失败分析

**问题**: 测试在刷新页面后无法获取侧边栏项目名（返回 null）

**根本原因**: 
1. 测试使用 `/create` URL 进入页面，发送消息后项目创建，但 URL 未更新为 `/create/{projectId}`
2. 刷新页面时，由于 URL 中没有 projectId，页面回到初始状态（显示"开始你的项目"）
3. 这导致 `getSidebarProjectName` 选择器找不到项目列表项

**这不是产品 Bug**: 
- 后端 `_sync_project_name_from_skill_state` 单元测试全部通过
- 手动改名测试通过，说明项目名更新机制工作正常
- 失败是测试代码的 URL 处理逻辑问题

## 问题与建议

### 测试代码问题（非产品问题）

**问题**: E2E 测试刷新后无法恢复项目状态

**建议修复**:
```typescript
// 在刷新前获取 projectId 并导航到带 ID 的 URL
const projectId = await page.evaluate(() => {
  // 从页面状态或 URL 获取 projectId
  return window.location.pathname.match(/\/create\/([^\/]+)/)?.[1];
});

if (projectId) {
  // 确保 URL 包含 projectId
  await page.goto(`${CREATE_URL}/${projectId}`);
}

// 然后再刷新
await page.reload({ waitUntil: 'domcontentloaded' });
```
