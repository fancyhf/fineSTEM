### Q-024 修复详情

**根因**: 前端 `createProjectViaAPI` 只在 `directCodingIntent`（用户明确要求写代码）时调用。对于普通消息（如"我想做一个待办事项应用"），不创建 API 项目，WS daemon 用 `project_creator` 工具创建的项目归属服务账号 → autosave 全部 403。

**修复**: `Create.tsx` 将条件从 `directCodingIntent && !effectiveProjectId && user` 改为 `!effectiveProjectId && user`，确保所有登录用户首次发消息时都通过 API 创建项目。
