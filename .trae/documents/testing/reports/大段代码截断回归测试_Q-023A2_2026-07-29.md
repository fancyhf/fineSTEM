### 4.5 TC-DLG-034: 多次续接按钮不消失

**验证方式**: 代码审查 + 已有测试覆盖

**修复确认**:
1. ✅ `!isContinueMessage` 守卫已移除
2. ✅ `manualContinueCountRef` 计数器已添加（上限 4 次）
3. ✅ 达上限后按钮隐藏（防死循环）
4. ✅ 新对话后计数重置

**相关代码** (`useStreamingChat.ts`):
```typescript
// 手动续接计数
const manualContinueCountRef = useRef(0);
const MAX_MANUAL_CONTINUES = 4;

// 检查是否达到上限
if (manualContinueCountRef.current >= MAX_MANUAL_CONTINUES) {
  console.log('[Streaming] 已达手动续接上限，不再显示继续按钮');
  return;
}
```

**判定**: ✅ **通过**
