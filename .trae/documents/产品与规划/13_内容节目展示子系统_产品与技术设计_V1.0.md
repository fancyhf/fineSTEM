## 1. 定位与目标

### 1.1 是什么

一个**内容节目频道**：以"系列 → 节目（集）"的结构，集中展示两个 IP 的系列内容：

| 内容品牌 | 系列（规划） | 节目构成 |
|------|------|------|
| 鸡娃先自鸡 | 如《递推之美》等数学科普系列 | 一次一个话题：互动动画 web + 家长视频 + 儿童视频 + 策划案/资料 |
| fineSTEM | fineSTEM 课堂（PBL 视频课程） | 一次一个话题：讲解视频 + 平台项目展示 + 配套资料 |

节目 = 最小内容单元，承载：标题、说明、面向对象（家长/孩子/亲子）、互动 web、视频（按受众分）、文档资料。

### 1.2 部署形态（本设计的硬约束）

与 fineSTEM **同一台云服务器、同一个一级域名**，但**独立子域名、独立入口、独立视觉风格**：

- 服务器：腾讯云轻量香港 2C2G（43.128.8.131），已跑 Nginx + FastAPI(8001) + ZeroClaw
- 主站：`wostemstudio.site`（fineSTEM 平台，保持不动）
- 本子系统：`show.wostemstudio.site`（新增子域名，复用同一后端进程与证书体系）
- **新增成本：¥0**（子域名 DNS 记录免费、Let's Encrypt 证书免费、无新进程）
- 页面风格与 fineSTEM 主站（teal 色工具型 SaaS 风）**完全不同**：采用与"鸡娃先自鸡"IP 调性一致的**纸墨风**（见 §6）

### 1.3 不做什么（边界）

- 不做用户系统、评论、弹幕、付费——起步期纯展示 + 观看
- 不做后台编辑器——内容用"文件即内容"（content-as-code）方式发布，与现有策划案/脚本工作流（`G:\buddyspace\鸡娃先自鸡\`）衔接
- 不动 fineSTEM 主站任何页面；仅可选在主站导航加一个外部入口链接

## 2. 总体架构

```text
浏览器
  │
  ├─ https://wostemstudio.site          → fineSTEM 主站（现状不动）
  │
  └─ https://show.wostemstudio.site     → Show 子系统（新增 nginx server block）
        │
        ├─ /                → /opt/finestem/show/dist      （Show 前端静态，SPA fallback）
        ├─ /api/v1/show/*   → proxy → 127.0.0.1:8001      （复用 finestem-backend，新增只读路由）
        └─ /content/*       → alias  /opt/finestem/show/content/  （节目资源：动画 html / mp4 / 封面 / 文档）
```

要点：

1. **前端**：新建轻量 Vite + React + TS 应用 `apps/show`（仓库内 monorepo 位置），只依赖 react / react-dom / react-router-dom。不引入 tailwind / monaco / webcontainer，用纯 CSS 变量做主题，保证体积小、风格完全可控。
2. **后端**：复用 `finestem-backend`（8001 端口，无新 systemd 服务），新增 `app/api/show.py` 只读路由，从内容目录读 JSON + 资源清单，内存缓存（按 mtime 失效）。
3. **内容**：`content/show/` 目录即内容库（git 版本管理），结构见 §4。发布 = 同步目录到服务器，无需重启、无需重新构建前端。
4. **互动动画 web**：现有形态是独立 HTML 文件（如《第1集_递推之美_搭积木版.html》，16:9 自适应画布），**原样作为静态资源托管、iframe 嵌入**，不做二次开发。
5. **视频**：**一律外部嵌入（B 站 embed 等），服务器本身不存 mp4**。视频号无法外嵌，长视频主阵地 B 站，链接形态 `//player.bilibili.com/player.html?bvid=…`。

## 3. 信息架构与页面设计

### 3.1 站点地图

```text
/                         频道首页（节目流：筛选 + 搜索）
/series/:slug             系列页（系列介绍 + 集列表）
/ep/:seriesSlug/:epSlug   节目详情页（核心页面）
/ep/:seriesSlug/:epSlug/play   互动全屏页（iframe 沉浸模式）
```

URL 用语义化 slug 而非数字 id，便于口播/公众号引用：`show.wostemstudio.site/ep/recursive-beauty/ep01`。

交互规则：

- **三个筛选维度可叠加**：系列（单选）× 面向（单选）× 标签（多选），叠加后实时过滤卡片流，无刷新
- **搜索框**：对标题、说明、标签做包含匹配（前端已有全量列表，纯客户端过滤即可；接口同时支持 `q` 参数留扩展余地）
- **卡片信息**：封面、标题、一句话说明、集数徽标（朱砂印章样式）、面向徽标、资源类型小图标（互动 ▶视频 📄图文）
- **本期主打位**：内容目录 `index.json` 手工指定（默认取最新发布），封面点击直达详情页
- 空结果态：显示"没有找到相关节目" + 清除筛选按钮

### 3.3 系列页 `/series/:slug`

- 系列 header：系列名、副标题、简介、主题色条（每个系列一个主题色，纸墨底上的一个辅助色）
- 集列表：按集数倒序/正序可切换，行式列表（封面缩略 + 标题 + 一句话 + 面向徽标），或竖向时间线（体现"连载中"感，默认时间线，最新在上）
- 系列级资料（如系列总策划案）挂在本页底部资料区

### 3.4 节目详情页 `/ep/:seriesSlug/:epSlug`（核心页面）

```text
│ ──────────────────────────────                              │

│ ──────────────────────────────                              │
│ 本集资料                                                      │

└──────────────────────────────────────────────────────────────┘
```

交互规则：

- **tabs 由节目资源清单驱动**：有哪种资源才出现哪个 tab，默认激活顺序：儿童视频 → 互动演示 → 家长视频 → 第一个可用资源（亲子场景优先孩子内容；可在 episode.json 里 `default_tab` 覆盖）
- **视频 tab**：一律外部 embed iframe（B 站播放器 `//player.bilibili.com/player.html?bvid=…&autoplay=0`），懒加载；资源未上线时显示占位 tab + announce 提示文案
- **互动演示 tab**：`<iframe src="/content/series/<s>/<ep>/interactive/index.html" sandbox="allow-scripts allow-same-origin allow-pointer-lock">`，懒加载（切到 tab 才加载），16:9 容器内缩放；"全屏 ⛶"跳 `/play` 页
- **说明区**：markdown 渲染（复用或精简版 MarkdownText，不引入新依赖也可先做纯段落 + 换行）
- **资料区**：文档列表直链 `/content/...`，新窗口打开；fineSTEM 系列额外有"相关项目"区块，链接回主站 explore 页
- **上下集导航**：同系列内按 `episode_no` 相邻导航；无相邻则隐藏
- 页面底部极简 footer：频道介绍入口 + fineSTEM 主站入口（"内容中提到的项目，在 fineSTEM 制作 →"）

### 3.5 互动全屏页 `/play`

整个视口一个 iframe（动画本身已是 16:9 视口自适应、纸色底，全屏体验就是动画本身），右上角悬浮"退出全屏"。用于投屏/学习机/电视场景——符合 IP 规划中"孩子向产品必须支持多端独立观看"的并行消费原则。

### 3.6 移动端

- 首页卡片单列、筛选 chips 横向滚动、搜索框置顶吸顶
- 详情页 tabs 变为上下排布的区块（视频区置顶，资源区块纵向堆叠），家长视频/儿童视频两个醒目入口按钮
- 互动动画横屏 16:9 自适应，竖屏时提示"横屏体验更佳"（动画画布本身按 vmin 缩放，竖屏也能看，仅提示不强转）
- 亲子受众主要在手机/微信内打开：`viewport` 正确配置、分享 meta（微信卡片标题/描述/封面，P1）

## 4. 内容模型（content-as-code）

### 4.1 目录结构（仓库内 `content/show/`，服务器 `/opt/finestem/show/content/`）

```text
content/show/
├── index.json                          # 首页配置：featured（本期主打）、导航标签聚合等
├── series/
│   ├── recursive-beauty/               # 系列 slug《递推之美》
│   │   ├── series.json                 # 系列元信息
│   │   ├── ep01/                       # 节目 slug
│   │   │   ├── episode.json            # 节目元信息 + 资源清单（唯一需要编辑的文件）
│   │   │   ├── cover.svg                # 封面 16:9（SVG 生成或 jpg，<300KB）
│   │   │   ├── interactive/
│   │   │   │   └── index.html          # 互动动画 web（独立 HTML，可带 assets/ 子目录）
│   │   │   └── docs/
│   │   │       ├── 家长观看指引.md
│   │   │       └── 第1集_策划案.pdf
│   │   └── ep02/ …
│   └── finestem-class-01/              # fineSTEM 课堂系列
│       └── ep01/ …
└── assets/                             # 频道级公共资源（logo、默认封面、字体）
    └── fonts/                          # 自托管 webfont（见 §7.4）
```

规则：

- `status: draft` 的节目接口不返回，可先传服务器占位
- 大文件（mp4、psd 素材）不进 git：仓库只留 JSON + 封面 + 动画 html；视频走发布脚本单独上传（§7.3）
- 动画 html 从策划工作区（如 `G:\buddyspace\鸡娃先自鸡\...代码动画\`）复制为 `interactive/index.html`，不改内容

## 5. API 设计（只读、公开、无鉴权）

新增 `apps/backend/app/api/show.py`，挂现有 `/api/v1` 前缀下（`/api/v1/show`），实现为 `app/services/show_content.py`：启动后扫描内容目录构建内存索引，请求时比对 *.json 指纹（路径+mtime）决定是否重建——发布即生效，无需重启。

| 接口 | 说明 |
|------|------|
| `GET /api/v1/show/home` | featured 节目 + 全部系列摘要 + 全部已发布节目 + 标签云（首页一次拉全量，客户端筛选） |
| `GET /api/v1/show/series/{slug}` | 系列详情 + 集列表（含每集资源类型摘要，不含正文） |
| `GET /api/v1/show/episodes` | 节目列表，支持 `q`（标题/摘要/标签包含匹配，LIKE 即可）、`tag`（多值）、`audience`、`series`、`page/page_size`。前端数据量小，首页一次拉全量客户端过滤，此接口主要为搜索扩展与 SEO 预留 |
| `GET /api/v1/show/episodes/{series}/{slug}` | 节目完整信息（含 description_md、全部资源） |

响应字段与 §4 的 JSON 一一对应（服务端补全绝对 URL：`/content/...`）。错误码沿用现有规范；`CORS_ORIGINS` 增加 `https://show.wostemstudio.site`（同域代理下其实非必需，做双保险）。

## 6. 视觉设计规范（编辑部风 v2 · 与主站差异化）

> 2026-08-24 改版：负责人反馈初版纸墨童趣风"不是给成人看的"。频道外壳（页面本身）受众是家长，
> 改为**克制的编辑部/杂志风**；舞台内嵌入的互动动画保留童趣纸墨风（内容给孩子，外壳给家长）。
> 字体仍全部自托管（`@fontsource/noto-serif-sc` 500/700，无外部 CDN）。

### 6.2 排版与组件语言（v2）

- 面向徽标：家长 = 墨色细线小签「家长」，儿童 = 系列主题色小签「儿童」，亲子 = 双签
- 造型语言：小圆角（2–4px）、细线边框、无硬投影；卡片 hover 仅 -2px 抬升 + 边框加深 + 极淡阴影
- 封面为内容资产，随节目走编辑部风底版（宋体标题 + 卷次方章 + 降饱和主色插图）

## 7. 部署设计（增量，全部可逆）

### 7.1 DNS 与证书（一次性）

```bash
# DNSPod 控制台：添加 A 记录  show → 43.128.8.131
# 服务器上签发证书（独立一张，不动主站证书）：
certbot --nginx -d show.wostemstudio.site
```

### 7.2 Nginx 新增 `/etc/nginx/sites-enabled/show.conf`

```nginx
server {
    listen 80;
    server_name show.wostemstudio.site;
    return 301 https://$host$request_uri;
}
server {
    listen 443 ssl http2;
    server_name show.wostemstudio.site;

    ssl_certificate     /etc/letsencrypt/live/show.wostemstudio.site/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/show.wostemstudio.site/privkey.pem;

    # 前端静态（apps/show 构建产物）
    root /opt/finestem/show/dist;
    index index.html;

    # 复用同一后端（保留 /api/ 前缀，与主站同规则）
    location /api/ {
        proxy_pass http://127.0.0.1:8001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 内容资源：封面/动画/字体/文档（视频走 B 站嵌入，不落盘）
    location /content/ {
        alias /opt/finestem/show/content/;
        add_header Cache-Control "public, max-age=3600";
        charset utf-8;
    }

    # SPA fallback
    location / { try_files $uri $uri/ /index.html; }
}
```

验证：`nginx -t && systemctl reload nginx`。

### 7.3 发布 SOP

- **代码发布**（改前端/后端）：`apps/show` → `npm run build` → 同步 `dist/` 到 `/opt/finestem/show/dist`；后端走现有 git pull + `systemctl restart finestem-backend`
- **内容发布**（新一集）：本地 `content/show/` 编辑 JSON + 放资源 → `npm run validate:content`（JSON schema + 必填字段 + 引用文件存在性校验，P0 内置）→ 视频/大文件单独 scp 到对应目录 → rsync 其余到 `/opt/finestem/show/content/` → 自动生效（mtime 缓存失效），无需重启
- 建议写一个 `deploy/show-publish` 脚本收敛以上步骤（P0 交付物之一）

### 7.4 字体与带宽

- **字体**：全站自托管，**不使用 Google Fonts CDN**（大陆访客慢/不稳）。Show 前端通过 `@fontsource/zcoolkuaile`、`@fontsource/zcool-qingke-huangyou` npm 包引入（构建产物自带 woff2 分片子集，按 unicode-range 懒加载）；互动动画 HTML 引用内容目录下的同一套字体文件 `content/show/assets/fonts/`，接入第 1 集时把原 Google Fonts `<link>` 替换为本地路径即可
- **带宽**：视频全部走 B 站嵌入，不占用服务器带宽；`/content/` 只承载封面、动画 html、字体与文档，量级极小

## 9. 风险与对策

| 风险 | 对策 |
|------|------|
| 视频平台政策变化（B 站嵌入限制/防盗链） | 资源模型按"每条视频独立条目"设计，可随时换平台或切自托管 mp4（nginx 已支持 Range），前端只改数据 |
| 大陆访问 Google Fonts 慢 | 自托管子集化字体，新内容规范默认本地字体（§7.4） |
| 内容与代码耦合漂移（JSON 手误） | 发布前强制 `validate:content`（schema + 文件存在性），校验不过不上传 |
| 与主站风格混淆/品牌混淆 | 独立子域名 + 独立设计系统 + 独立入口；仅在详情页"相关项目"单向跳主站 |
| 单点服务器故障影响两站 | 已是现状（同一台），不新增风险；沿用每日 SQLite 备份 + 建议 scp 回本地 |
