# 精选和灵感墙功能问题说明 v1.0

**文档日期**：2026-08-02  
**文档状态**：问题汇总，待重构

---

## 一、业务需求

### 1.1 精选 Demo
- 管理员可以将项目标记为"精选 Demo"
- 精选 Demo 展示在首页
- 需要支持选入和撤回操作

### 1.2 精选作品
- 管理员可以将项目标记为"精选作品"
- 精选作品展示在首页
- 需要支持选入和撤回操作

### 1.3 灵感墙
- 用户可以将自己的项目发布到"灵感墙"（公开）
- 用户可以从灵感墙撤回自己的项目
- 管理员可以取消任何项目的灵感墙状态
- 灵感墙内容展示在首页

### 1.4 管理需求
- 管理员需要一个管理页面，查看和管理所有项目的精选状态和灵感墙状态
- 需要支持按标签筛选：全部项目、我的项目、精选 Demo、精选作品、灵感墙
- 需要显示统计信息：各分类的项目数量

## 二、涉及的页面和UI

- 精选 Demo 展示区
- 灵感墙内容展示区

const [demoRes, cardsRes, featuredRes] = await Promise.all([

**位置**：`apps/frontend/src/pages/ProjectDetail.tsx`

**功能区域**：

  - "选入/撤回精选 Demo"按钮

**当前实现**：

### 2.3 精选管理页（AdminFeatured.tsx）

**当前状态**：已恢复为原始版本

- 只管理成果档案卡的精选状态（achievement_cards 表的 is_featured 字段）
- 不涉及精选 Demo 和灵感墙的管理

## 三、涉及的数据库表

### 3.1 projects 表
**用途**：存储用户创建的研学项目

**相关字段**：
- `is_featured_demo` (BOOLEAN) - 是否作为精选 Demo
- `is_featured_work` (BOOLEAN) - 是否作为精选作品
- `visibility` (VARCHAR) - 可见性：private/link/public
- `featured_demo_sort_order` (INTEGER) - 精选 Demo 排序权重
- `featured_work_sort_order` (INTEGER) - 精选作品排序权重

### 3.2 demos 表
**用途**：存储系统预设的 Demo 模板

**相关字段**：
- `is_public` (BOOLEAN) - 是否公开

### 3.3 achievement_cards 表
**用途**：存储项目完成后生成的成果档案卡

**相关字段**：
- `is_featured` (BOOLEAN) - 是否作为精选作品
- `is_public` (BOOLEAN) - 是否公开到灵感墙
- `featured_sort_order` (INTEGER) - 精选排序权重

## 四、涉及的后端 API

| 接口 | 方法 | 功能 | 操作表 |
|------|------|------|--------|

## 五、当前现象

### 5.1 数据不一致
- 首页显示的数据和项目详情页设置的数据不一致
- 精选管理页面显示的项目数量和实际数据库中的数量不符

### 5.2 数据源混乱
- 首页从 demos 表和 achievement_cards 表读取数据
- 项目详情页写入 projects 表
- 精选管理页管理 achievement_cards 表

### 5.3 具体表现
- 精选 Demo 标签页只显示 1 个项目（实际应该有更多）
- 精选作品标签页只显示 1 个项目
- 灵感墙标签页只显示 1 个项目
- 首页能正常显示多个项目
