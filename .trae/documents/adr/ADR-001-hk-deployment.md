# ADR-001: 香港部署方案 (腾讯云轻量入门型 + 直连 + Let's Encrypt)

- **状态**: Accepted (已落地)
- **日期**: 2026-08-22 (定方案) / 2026-08-23 (修正为实际落地形态)
- **决策者**: AI Agent + 项目负责人
- **替代方案**: 北京 Lighthouse、Windows 宝塔、阿里云香港、京东云香港、Cloudflare 全家桶、EdgeOne
- **links**: `.trae/documents/技术与架构/香港生产环境部署文档_v1.0.0.md`, `.trae/documents/governance/domain-and-dns-policy.md`

---

## 1. 背景与上下文

fineSTEM 之前的部署形态：

1. **北京 Lighthouse** (IP: 43.140.204.127) — Docker Compose 多项目路径分发
2. **Windows 宝塔服务器** (IP: 122.51.71.4) — IIS/Nginx + Python 直跑

两项均存在以下问题：

- 国内访问需 ICP 备案，流程长且内容受限
- 无 HTTPS/域名，用户体验差
- 北京节点对国外用户访问慢
- Windows 宝塔方案资源占用高，Docker Compose 运维复杂
- ZeroClaw 从未真正部署上云，云端方案是早期遗留，已废弃

新需求：**部署到香港服务器 + 支持国内外访问 + 注册域名 + 优选腾讯系服务**。

---

## 2. 决策（实际落地形态）

> 注：初版 ADR 曾规划「锐驰型 2核2G + EdgeOne 边缘加速」，实际采购与落地时已调整——项目负责人选择**入门型 2核2G（¥38/月）且不使用 EdgeOne**，改用 Let's Encrypt 直连方案，理由是小规模公益项目追求最低成本、几十用户场景无需 WAF/DDoS。

### 2.1 选型结论

| 层 | 选型 | 规格/价格 | 理由 |
|----|------|----------|------|
| 服务器 | 腾讯云轻量 Lighthouse 香港**入门型** 2核2G | 40G SSD / 20Mbps / 512G 流量 ¥38/月 | 最低成本，小规模用户够用，免备案 |
| 操作系统 | Ubuntu 22.04 LTS | Linux，无图形界面 | systemd 支持完善，ZeroClaw 官方提供 Linux x86_64 二进制 |
| 域名注册 | 腾讯云/DNSPod 注册 **wostemstudio.site** | ~¥6/年 (.site 后缀) | 与服务器同账号，人民币付款 |
| DNS 解析 | DNSPod 免费版 | 免费 | 域名解析到服务器 IP |
| SSL 证书 | Let's Encrypt 免费 | certbot 自动签发+续签 | 直连 HTTPS，无需 EdgeOne |
| AI 底座 | ZeroClaw v0.8.4 Linux 二进制 | 免费 | 官方提供 x86_64 发布版 |
| 数据库 | SQLite (WAL 模式) | 免费，单文件 | 随项目迁移，当前用户量级无瓶颈 |
| 进程管理 | systemd | 免费 | ZeroClaw + FastAPI 守护 |
| 反向代理 | Nginx | 免费 | 前端静态 + API/WS 反代 |

### 2.3 端口规范

| 端口 | 服务 | 暴露范围 | 说明 |
|------|------|---------|------|
| 80 | Nginx (HTTP) | 0.0.0.0 | 301 跳转 HTTPS |
| 443 | Nginx (HTTPS) | 0.0.0.0 | 前端 + API + WS 反代，Let's Encrypt 终结 |
| 8001 | FastAPI 后端 | 127.0.0.1 | 通过 Nginx `/api/` 反代 |
| 42617 | ZeroClaw Gateway | 127.0.0.1 | 通过 Nginx `/ws/chat` 反代 |

**所有业务端口只绑 127.0.0.1，对外只通过 Nginx 443 暴露。**

### 2.4 高峰错峰调用策略

- **白天高峰（北京 9-12、14-18）**：`assistant_qwen` → 百炼 qwen（避免 DeepSeek 高峰拥堵）
- **夜间/非高峰**：`assistant` → DeepSeek
- 配置收敛在 `H:\dev-env\zeroclaw\config\config.toml`（开发环境）与 `/opt/zeroclaw/config/config.toml`（生产环境）单处，详见部署文档 §6。

## 3. 替代方案与拒绝理由

| 方案 | 月成本 | 拒绝理由 |
|------|-------|---------|
| 北京 Lighthouse (保留现状) | — | 需 ICP 备案，国外访问慢 |
| Windows 宝塔 (保留现状) | — | 资源占用高，Docker 运维复杂，ZeroClaw 未上云 |
| 阿里云香港国际型 (BGP_NCO) | ¥39 | 国内延迟 80-120ms + 丢包 2-5%，不可用 |
| 阿里云香港 BGP 优化 | ¥107 | 同档比腾讯贵 2 倍，带宽仅 10Mbps |
| 京东云香港 | ¥47 | 带宽仅 2Mbps，AI 流式必卡 |
| Cloudflare 全免费 | ¥0 | Workers AI 免费版不支持流式，无法承载 ZeroClaw |
| Cloudflare + 香港服务器混合 | ¥38 | 免费版国内无节点，延迟 80-200ms |
| 腾讯云锐驰型 2核2G | ¥55 | 比入门型贵 45%，小规模场景没必要 |
| **EdgeOne 边缘加速** | ¥0 起 | 几十用户场景无需 WAF/DDoS；直连香港延迟已 10-20ms，加 EdgeOne 反增复杂度 |

## 5. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 2核2G 内存紧张 | OOM 风险 | 不装宝塔，AI Agent 通过 SSH 运维；已验证运行稳定 |
| 20Mbps 带宽 + 512G 流量上限 | 大文件下载限速 | 学生作品以 SQLite+小图为主，当前 17MB 数据无压力 |
| SQLite 高并发写入锁 | 性能瓶颈 | WAL 模式；几十~几千用户无瓶颈，未来迁 MySQL |
| Let's Encrypt 90 天过期 | HTTPS 中断 | certbot 已配自动续签（systemd timer） |
| DeepSeek/百炼 API 从香港调用 | 可能受限 | 已实测可用；高峰切百炼兜底 |

---

## 6. 合规说明

- 香港服务器免 ICP 备案
- 域名使用境外服务器 + 直连，不强制备案
- 数据存储在香港服务器，遵循《个人资料（隐私）条例》（香港法例第 486 章）
- 密钥管理：LLM API Key 单处配置（config.toml），不在代码仓库明文存储

---

## 7. 后续演进路径

1. **用户量增长到 5000+**：升级到 2核4G 锐驰型 ¥95/月
2. **并发写入瓶颈**：SQLite → 腾讯云 MySQL
3. **国内加速/合规需求**：补办 ICP 备案，或接入 EdgeOne 含大陆节点
4. **对象存储需求**：学生作品文件 → 腾讯云 COS / Cloudflare R2
