# 任务卡集（task-cards）

- 适用模型：eco-island-v1（冻结）；作品代码：B 包 reference/starter/checkpoints（2026-11-03 版）
- 读者：12–15 岁自学少年；每张卡没有老师在场也能读懂。
- 用卡方式：按编号顺序做。每张卡独立成篇——卡住了只看当前卡的"分级提示"，**从第 1 级开始逐级看，看到能动手就停**。
- 两条平台铁律（来源：G 包 platform-check §4，2026-11-02 生产站实测）：
  1. **代码一律走编辑器粘贴**——不要从 AI 聊天记录里复制代码（聊天管道会清洗损坏代码）。
  2. **不轻信"我已经写好了"**——保存后刷新页面，自己看到代码和运行结果才算数。
- 记录工具：D 包 8 份模板（`交付/D_文档汇报/templates/`），每张卡"保存什么"会指到具体模板。

## 任务卡 0｜开工：定目标、排三个任务

- **目标**：用两句话写下你要做什么、做成什么样算完成；把整个复刻拆成三个任务。
- **前置**：无。这张卡开始前，建议先试玩过参考版 5 分钟（知道终点长什么样）。
- **操作**：
  1. 打开 D 包模板《01-开题》，填两栏：我要做什么 / 我做出的东西怎么算成功（写"能看到的证据"，不写"学会"）。
  2. 打开模板《03-任务计划》，把复刻拆成三个任务（示例拆法：①跑通三关看懂规则 ②修好 starter 的 5 个 TODO ③完成一次改造并有前后对比记录）。每个任务写"完成时会有什么产出"。
  3. 把两个文件存到你的项目文件夹。
- **分级提示**：
  - 级 1：目标句式可以用"做出一个能 ______ 的网页，我能指出 ______"。
  - 级 2：三个任务每个要有可检查的产出（一个文件、一次运行截图、一张对照表），"理解了"不算产出。
  - 级 3：任务顺序建议先"看懂"再"动手"再"改造"——和本卡集 1→3→4~8→9 的顺序一致。
- **自查**：[ ] 目标里有可检查的证据　[ ] 恰好三个任务　[ ] 每个任务有产出描述
- **常见错误**：目标写成"学会生态学"（不可检查）；任务拆成十个（拆不动）。
- **保存什么**：`01-开题.md`、`03-任务计划.md`。
- **下步入口**：任务卡 1。

## 任务卡 1｜第 1 关：认识小岛（只看，不点）

- **目标**：打开第 1 关程序，指认三个状态、一处步数、两条日记——建立"第 0 步世界"的概念。
- **前置**：任务卡 0 完成。
- **操作**：
  1. 打开 `交付/B_作品代码/checkpoints/01-static/eco-island.html`（本地双击；平台上则把文件内容粘贴进编辑器→保存→运行）。
  2. 不点任何按钮，只观察。对照第 1 关 `checkpoint.md` 的 7 条清单逐条打勾。
  3. 用手指着屏幕说出：三个数各是多少、哪里显示步数、日记里写了两行什么。
- **分级提示**：
  - 级 1：注意画面右侧四张卡的颜色——绿、橙、蓝分别对应什么？
  - 级 2：步数在画面下方一行小字："⏱️ 第 0 步 / 共 60 步"。
  - 级 3：三个数是 0–100 的**教学指数**，不是真实草公斤数/动物只数/水量（知识第 1 章）。
- **自查**（对齐 checkpoint.md）：[ ] 三个数 60/20/50　[ ] 第 0 步/共 60 步　[ ] 日记两行（"小岛重新开始…"和"猜猜看…"）　[ ] 能说出指数不是真实数量
- **常见错误**：把三个数当真实数量（"60 棵草"——错，是指数）；找不到日记（右侧最下面一张卡"📔 小岛日记"）。
- **保存什么**：一张第 0 步截图（进《05-开发与调试》或你的记录文档）。
- **下步入口**：任务卡 2。

## 任务卡 2｜第 2 关：走一步 + 手算对照（含一次完整手推）

- **目标**：亲手单步走 3 步；每步**先手算预测、再点按钮对照**，三步全对。这是任务书要求的"一次小数据手推"。
- **前置**：任务卡 1；读过知识第 1 章的四步顺序。
- **操作**：
  1. 打开 `checkpoints/02-single-step/eco-island.html`（本关解锁了【⏭️ 走一步】【🔄 重来】）。
  2. 纸笔手算第 1 步（从 60/20/50）：草 = 60+2−20×0.8 = ？动物变不变？水 = 50+3−20×0.3 = ？**写下预测再点【走一步】**。
  3. 同法手算并对照第 2、3 步（参考 checkpoint.md 的手算对照表——先自己算，再对表）。
  4. 回答："为什么第 3 步动物才开始变少？"
- **分级提示**：
  - 级 1：顺序口诀"先长 → 再吃 → 再决定动物去留 → 最后算水"。
  - 级 2：第 2 步要从**第 1 步的结果**接着算（每步输出 = 下步输入）；扣水用**旧动物数**。
  - 级 3：第 3 步手算草 = 32+2−16 = 18，18<20 触发"草<20 → 动物−3"。
- **自查**（对齐 checkpoint.md）：[ ] 先写预测再对照（三步都是）　[ ] 三步全对（误差 ≤0.1 归四舍五入）　[ ] 能说出第 3 步动物减员的原因　[ ] 试过【重来】回到 60/20/50
- **常见错误**：手算用"吃过之后的草"判断动物，但忘了是**先长后吃**（60 先 +2 再 −16）；水算错是因为用了新动物数（应该用旧数）；数字带小数慌了（正常，模型保留两位小数）。
- **保存什么**：手算纸拍照或抄进 D 模板《04-设计与算法》"手推一次"栏。
- **下步入口**：任务卡 3。

## 任务卡 3｜第 3 关：完整实验（60 步 × 3 个对照）

- **目标**：跑完三个 60 步实验（默认/初始动物 5/大雨档），每个记下第 60 步三数，能说出"哪里不一样、为什么"。
- **前置**：任务卡 2。
- **操作**：
  1. 打开 `checkpoints/03-full-control/eco-island.html`（全部解锁）。
  2. 实验 1（默认）：直接【▶️ 开始】跑完 60 步。盯"📔 小岛日记"，抄下关键事件和第 60 步三数。
  3. 实验 2：【🔄 重来】→ 初始动物滑杆调到 5 → 重跑。动物还灭绝吗？
  4. 实验 3：重来 → 下雨档改【⛈️ 大雨】→ 重跑。水一直满吗？动物呢？
  5. 每个实验把"第 60 步：草/动物/水"写进一张三行对照表。
- **分级提示**：
  - 级 1：跑得快慢（🐢/🚶/🐇）只改看得多快，不改任何一步的结果——可以试一次验证。
  - 级 2：滑杆改动要按【🔄 重来】才生效；下雨档位要【⏸️ 暂停】才能改（跑步中改会被弹回）。
  - 级 3：默认局实测锚点：第 5 步草光、第 9 步动物归零、第 29 步水满、第 34 步迁回、第 60 步 = 草 20.8/动物 4/水 100（test-cases.json TC09）。你的运行应与之完全一致——不一致说明代码被动过。
- **自查**（对齐 checkpoint.md）：[ ] 三个实验都有第 60 步记录　[ ] 能说出三局哪里不同、为什么　[ ] 验证过"速度不改变结果"　[ ] 知道滑杆/雨档各自的生效时机　[ ] 对照过 reference 确认观察没错
- **常见错误**：改滑杆没按重来就开跑（改了等于没改）；实验 3 看到动物照样第 9 步归零以为程序坏了（没有——知识第 3 章：雨不是短板）。
- **保存什么**：三行对照表 → D 模板《06-配置与测试》；两句"哪里不一样、为什么" → 《05-开发与调试》。
- **下步入口**：任务卡 4（开始 starter 挑战）。

- **分级提示**：

## 任务卡 8｜starter TODO ⑤：动物灭绝的警报哑了

- **目标**：修好小岛日记的灭绝警报——动物归零那一刻必须说话。
- **前置**：任务卡 7。
- **操作**：
  1. 搜索最后一个 `TODO(学生)`："动物灭绝的警报哑了"。
  2. 现在代码：`if (false) addDiary("🐰 动物们饿肚子，全都离开小岛了……")`——条件写死为假，警报永远不响。
  3. 按提示把 `false` 换回真实条件："之前有动物，且现在变成 0"。
- **分级提示**：
  - 级 1（现象）：修复前跑到第 9 步，日记只会说"动物饿走了"（−3 那条），归零却没有专属警报。
  - 级 2（思路）：`narrate(prev, next)` 拿到前后两个状态。条件 = `prev.herbivores` 大于 0 **并且** `next.herbivores === 0`。参考隔壁行"草被啃光"警报的写法（`prev.grass > 0 && next.grass === 0`）——一模一样的模式。
  - 级 3（为什么两个条件都要）：只有 prev>0，动物已经归零后每步都会刷屏警报；只有 next===0，空岛开局（动物 0）第一天就误报。**"跨越检测"必须比较前后两个状态**（code-map 重点学习第 4 条）。
- **自查**：[ ] 默认局第 9 步日记出现"🐰 动物们饿肚子…"（红色条）　[ ] 动物 0 开局第一**不**触发警报　[ ] 能说出为什么用 `&&` 连接两个条件
- **常见错误**：只写 `next.herbivores === 0`（空岛误报）；把 `===` 写成 `=`（赋值不是比较，条件恒真刷屏）。
- **保存什么**：全部 5 处 TODO 的修复记录合成《07-变更记录》核心条目；修复完成后的运行截图。
