# 复刻总指南（replicate-guide）

- 适用：eco-island-v1（冻结模型）+ B 包 2026-11-03 版代码。
- 读者：想"把这个作品亲手做一遍"的 12–15 岁少年。全程自学可完成；AI 助教用法见《assistant-guide.md》。
- 总时长参考：试玩 3 关约 40 分钟；starter 修 5 处约 60–90 分钟；验收+改造约 60 分钟。可以分多次做。

## 0. 路线总览（一张图）

```
试玩参考版（3 关 checkpoints）
   ↓            任务卡 1–3
starter 挑战：修好 5 个 TODO(学生)
   ↓            任务卡 4–8
对照 reference 验收（4 个锚点时点）
   ↓            任务卡 9
选一个改造（干旱岛 / 参数比较 / 进阶）
                change-challenges.md
```

每一步都有"做什么 / 怎么知道做对了 / 卡住了怎么办"。任务卡细节在 `task-cards.md`，本指南只管路线和急救。

## 1. 第一步：选你的运行环境

**方式一（最简单，推荐先用）：本地双击**
- 把 B 包的文件拷到自己电脑，双击任意 `eco-island.html`，用 Chrome/Edge 打开。
- 怎么知道做对了：浏览器出现小岛画面、三个数字、四个按钮；按 F12 没有红色报错。
- 卡住了：换个浏览器试；确认文件是完整的 `.html`（文件大小约 20 KB；如果只有几 KB，说明拷贝不完整）。

**方式二：fineSTEM 平台（线上保存作品用这个）**
按 G 包已验证的手工路径（2026-11-02 生产站实测走通，platform-check §2.1）：

| 步 | 做什么 | 怎么知道做对了 | 卡住了怎么办 |
|---|---|---|---|
| 1 | 打开 https://wostemstudio.top/ 注册/登录 | 进入"创造"页 | 任意格式邮箱即可，无验证码 |
| 2 | 在输入框发一条项目开题（例："我要复刻一个生态岛模拟网页，包含草/动物/水三个状态和单步/运行控制"） | 平台自动创建项目，进入阶段流程 | 项目名=消息前 20 字，想好开头再发 |
| 3 | 取代码：**本地打开 B 包对应文件 → 全选复制**（本指南不推荐让 AI 直接生成整份长代码，原因见 §2） | 复制前看到完整 `</html>` 结尾 | 用系统记事本/VS Code 打开再复制，别用聊天窗口 |
| 4 | 粘贴进右侧 Monaco 编辑器（全选覆盖） | 编辑器行数与源文件一致（约 460 行） | 编辑器消失了 → **刷新页面**（平台已知偶发，G 包缺陷④） |
| 5 | 点【保存】 | 刷新页面后代码还在 | 保存后刷新发现是空的 → 重新粘贴再保存 |
| 6 | 点【运行】，右侧出预览 | 小岛画面出现，可玩 | 预览空白 → 检查粘贴是否截断（结尾必须是 `</html>`） |
| 7 | 项目改名、建成果档案卡（5 个必填字段）、同步能力标签 | 成果卡创建成功 | 缺字段会报错，按提示补全 |

**给孩子/家长的口径**：方式二的 1→6 就是"复刻一个项目"的最短路径；7 是保存成果。

## 2. 平台四条铁律（每一条都有真实事故记录，G 包 §4）

1. **代码一律走编辑器粘贴，不走聊天复制**。平台的聊天管道会清洗代码（丢代码围栏、过滤 `<option>` 等标签行）——从聊天记录复制代码 = 拿到一份悄悄损坏的代码。
2. **不轻信 AI 的"我已经写好了/已写入编辑器"**。平台实测出现过：AI 声称写入，编辑器其实是空的。核对方法：保存后刷新页面，自己看到代码；或核对行数/字符数。
3. **AI 导师直接生成长代码会被截断**。如果一定要向 AI 要长代码，用**分段协议**：让 AI 分 3 段、每段 ≤100 行、你说"下一段"它才继续（此协议 2026-11-02 实测有效）。拼完在编辑器里粘贴，再整体保存。
4. **编辑器偶发卸载（面板挂掉）= 刷新页面**。已保存的内容不会丢。

## 3. 第二步：试玩三关（任务卡 1–3）

- **做什么**：依次打开 `checkpoints/01-static` → `02-single-step` → `03-full-control` 的 `eco-island.html`，各关按对应任务卡做完自查清单。第 2 关必须完成一次完整手推（先写预测、再点按钮）。
- **怎么知道做对了**：第 2 关三步手算全对；第 3 关三个实验都有第 60 步记录，且默认局与实测锚点一致（第 9 步动物归零、第 60 步 20.8/4/100）。还要能答两道"解释算法"题：去留为什么排在吃草后面（先吃后定，62>50 会多来 2 只、46 不会）；50 和 20 两条线各管什么（草多加 2 只、草少减 3 只）——答案见知识第 1–2 章与任务卡 2/3。
- **卡住了怎么办**：手算对不上 → 回知识第 1 章四步顺序，检查"先长后吃""扣水用旧动物数"两个坑；实验现象和锚点不符 → 你打开的文件被改过，重新用 B 包原版。

## 4. 第三步：starter 挑战（任务卡 4–8）

- **做什么**：复制 `starter/eco-island.html` 为 `my-island.html`，搜索 `TODO(学生)` 共 5 处，**一处一卡、逐个修**（每处都有单独任务卡，含三级提示）。程序在未修状态下也能运行——它只是"能跑但不对劲"，这正是你要修的。
- **怎么知道做对了**：修完第③处（模型区最后一处）后，默认局第 1 步 = **草 46 / 动物 20 / 水 47**；五处全修完后与 reference 对照四个锚点全对（任务卡 9）。
- **卡住了怎么办**：
  - 页面报语法错误（一片白屏）→ 你刚改坏的那行多半缺引号/括号，撤销这行，看任务卡"常见错误"。
  - 改了没效果 → 确认改的是"搜索 TODO(学生)"定位的那行，别改到注释里的示例；确认保存并刷新了页面。
  - 五处全乱不知道哪错了 → 回到 B 包原版 starter 重新拷一份，一处一卡重来。**顺序修+每步验证**就是为了坏了能定位。

## 5. 第四步：对照 reference 验收（任务卡 9）

- **做什么**：你的版 vs 参考版同开局各跑 60 步，抽查 4 个时点：第 1 步 46/20/47、第 5 步 0/11/37.7、第 9 步 0.4/0/41.9、第 60 步 20.8/4/100（锚点出自 A 包 test-cases.json TC01/TC02/TC09）。
- **怎么知道做对了**：四点全对 + 小岛日记在相同步数出现相同事件（草光、归零警报、迁回）。
- **卡住了怎么办**：只有第 60 步对、中途不对 → 长链差异说明某处规则仍有小错，回去逐处对照 `stepModel` 与 code-map 的 5 处重点。

## 6. 第五步：改造（change-challenges.md）

- **做什么**：从你的 `my-island.html` 继续做"干旱岛"标准改造（推荐），或先做入门参数比较。
- **怎么知道做对了**：改造前后各有一份同配置 60 步记录；干旱岛改造用 A 包给的最小验收用例（V2-1/V2-2）验证，详见《改造挑战》§2。
- **卡住了怎么办**：改造"不生效"——十有八九是 `||` vs `??` 假值陷阱，直接看《改造挑战》§2.4。

## 7. 通用急救表

| 症状 | 原因 | 动作 |
|---|---|---|
| 平台编辑器面板消失 | Monaco 偶发卸载（已知缺陷） | 刷新页面；已保存内容不丢 |
| 保存后代码是空的/变短 | 粘贴被截断或竞态覆盖 | 重新粘贴→保存→刷新核对行数 |
| AI 说"已写入"但编辑器空 | AI 误报（已知缺陷②） | 不信声称，以刷新后自己看到的为准；改用分段协议要代码 |
| 双击本地文件打不开/白屏 | 文件不完整或改出语法错误 | 看文件结尾是否 `</html>`；按 F12 看红色报错行号 |
| 运行结果与锚点不符 | 代码被改动过 | 用 B 包原版重新拷贝；对照四点锚点定位 |
| 后台标签页跑得极慢 | 浏览器对后台页降频（环境现象） | 保持标签页在前台（录屏时尤其重要） |

## 8. 你需要保存的完整档案（对照 D 包模板）

1. `01-开题` + `03-任务计划`（开工时）
2. `04-设计与算法`（含手推一次，第 2 关时）
3. `05-开发与调试`（每修一处记一条，starter 期间）
4. `06-配置与测试`（三关实验对照表）
5. `07-变更记录`（starter 五处汇总 + 改造单）
6. `08-总结与AI帮助`（如实分清：参考代码 / AI 帮助 / 自己判断）
