## 3. 发现的六包间矛盾与过期表述（按影响排序）

### 3.1 【不一致，建议发布前修正】B code-map.md §模型规范摘要 2 处与 A 冻结规范矛盾

`交付/B_作品代码/code-map.md`（孩子看代码时的导读）两处表述与 A model-spec 及 B 自己的代码不符：

1. **"step≥maxSteps 状态不变"**——错。冻结模型（=B reference 实际代码）**模型层不检查 maxSteps**（A model-spec §6.2、TC10 实测：step=3/maxSteps=3 仍返回 step=4）。"到步即停"是**旧** `eco-island-reference.html`（范本目录）的行为，正是 A §6.3 警示的版本卫生陷阱；停机拦截在 v3 的**界面层**（60 步自动暂停+开始按钮拒绝，单步不拦截）。孩子拿这条去核对代码会得出错误结论。
2. **"全部 clamp 0–100"**——不准。grass **无上限截断**（A §6.1，TC05 中间值 100.5、S-G 实测存储值可超 100）；只有 herbivores/water 双向截断。

影响：C 任务卡引导孩子读 code-map（复刻路线依赖）；暂存包 docs 未收录 code-map，**不阻塞暂存包**，但发布前应由 B 修订（约 2 行改动）并按 01 §8 在其 HANDOFF 追加变更记录。
