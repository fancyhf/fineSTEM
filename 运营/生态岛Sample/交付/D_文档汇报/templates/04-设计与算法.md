# 04 设计与算法：数据、规则、手推一次

> 什么时候填：写代码之前；写代码卡住的时候，回来重读一遍也很有用。
> 大约需要：约 12 分钟。第 3 部分"手推一次"是整份最重要的。

## 1. 数据是什么

程序要记住哪几个数字（状态）？哪些是可以调的设置（配置）？

| 名字 | 含义 | 范围 | 状态还是配置 |
|---|---|---|---|
| 【示例】grass 草量 | 草的多少 | 0–100 教学指数 | 状态（每步会变） |
| 【示例】rain 档位 | 资源补充设置 | low/mid/high | 配置（可以调） |
|  |  |  |  |

（提示：状态值是 0–100 的教学指数，不是真实棵数或只数。真实生态的数量比这复杂得多。）

## 2. 规则怎么写

每一步按什么顺序更新？每条规则写成"如果……就……"。顺序会影响的：先吃草再长草，和先长草再吃草，结果不一样。

1. 【示例】先算草生长：如果水>0，草<80 时 +2，否则 +0.5；水=0（干旱）不长草。
2. 【示例】再算动物吃草：吃掉 = 动物数×0.8，草最少减到 0。
3. 【示例】再算动物增减：草>50 时 +2，草<20 时 −3，范围限 0–100。
