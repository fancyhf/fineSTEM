## 2. 缺项（无工具/无授权，如实列出）

| 缺项 | 影响 | 处置 |
|---|---|---|
| 无真人出镜/真人配音条件（无摄像头拍摄、无播音人） | 家长视频 M1（真人骨架镜头）不可拍；两部片配音均为 TTS 小样 | 家长片交付到执行卡+素材+排片样片层级；配音小样待用户按《音频与字幕生产_规范》铁律 2 确认后方可全量 |
| fineSTEM 平台账号凭证不在 F 环境 | 少年镜 6（平台保存操作）不可实录 | 用 2026-11-02 平台实测存档截图（B-E001/B-E002）+ 明示"存档画面非本次录制"横幅代过；待真人补录 |
| 无授权背景音乐来源 | 两部片**均无音乐** | manifest 标注"无音乐"；后续如需配乐须统筹提供授权来源 |
| gdigrab 不捕捉系统鼠标指针 | 录屏中看不到光标 | 用 CDP 注入的**指针 overlay**（pointer-events:none 的高层 div，跟随同源真实点击坐标）呈现操作位置；属呈现层辅助，不改动作品逻辑；已在 HANDOFF 声明 |
| 无专业非线性编辑软件（剪映/PR 未核查） | — | 全部合成走 ffmpeg，无需 GUI |
| edge-tts / GLM-TTS | 未实测（声源优先级表第 2/3 顺位，本次未用到） | 如复刻双声不可用时再启用 |

## 3. G 盘约束执行

- 本次所有进程启动均设置 `TEMP/TMP/TMPDIR=G:/tempcache/f-pkg/`；Chrome 用户数据目录、ffmpeg 中间产物、TTS 中间产物全部在该目录。
- ffmpeg concat 清单使用 `G:/` 原生 Windows 路径（《音频与字幕生产_规范》§五.4）。
- 交付成品只写入 `G:/mediaProjects/fineSTEM/运营/生态岛Sample/交付/F_媒体制作/`。

## 4. 口径与声源声明

- 少年旁白音色：**小雅声 S_5kGoqDYd2**（规范复刻双声之一；少年视角没有专属复刻音色，选双声中的少年/学生位；待统筹确认，必要时换真人少年配音重录音轨——脚本与时间轴不受影响）。
