## 开题消息全文（复刻可照抄）

我想做一个叫《生态岛：小岛为什么变了？》的生态模拟网页：一个小岛上有草和食草动物，我想观察"改变一个条件，哪些状态会跟着变化"。请直接给我一个可运行的完整版本，并自动写入编辑器。要求单文件 HTML，原生 HTML/CSS/JS，不用任何外部库，关键函数写中文注释。

模拟规则（严格按此实现，确定性计算，不用随机数）：
1) 状态对象 state = { step, grass, herbivores, water }，三个指数都是 0–100；配置对象 config = { modelVersion:'eco-island-v1', initialState, environment, maxSteps }。
2) 核心函数 stepModel(previousState, config) 返回新状态，不得修改旧状态；UI 与模型分离，stepModel 里不许操作 DOM。
3) 每步按固定顺序更新：
① 草生长：water>0 时 grass 增长（grass<80 时 +2，否则 +0.5），water==0 时干旱、不长草；
② 动物吃草：eaten = herbivores×0.8，grass = max(0, grass−eaten)；
③ 动物数量：草>50 时 +2，草<20 时 −3，否则不变，范围限 0–100；
④ 水分：water = water + 补充档位速度 − herbivores×0.3，限 0–100。补充档位：低=1，中=3，高=6，默认中。
4) 默认初始：grass=60, herbivores=20, water=50, maxSteps=60。

界面要求：
- 岛屿示意区（Canvas/CSS 均可）：绿色深浅表示草量、圆点表示动物、蓝色条表示水分，简单清楚就行
- 状态面板：草量/动物/水分三个指数和进度条，显示当前步数
- 控制按钮：开始、暂停、单步、重置；运行速度可选（快/中/慢），但速度不改变模拟结果
- 初始配置三个滑杆（初始草量/动物/水分）：只在点重置后生效，运行中修改要提示"重置后生效"
- 资源补充档位下拉框：暂停时可以修改，修改写入过程记录
- 过程记录：每 5 步记一行"第 N 步：草 xx｜动物 xx｜水 xx"；暂停/重置/改档位也各记一行，最多保留 20 条
