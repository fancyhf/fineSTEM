# 第 2 关：一步一变化（单步与手算对照）

文件：`eco-island.html`（直接双击打开）。本关可用：【⏭️ 走一步】【🔄 重来】。开始/暂停仍锁定。

## 本关目标

亲手单步推进，用**手算**预测每一个数，再和程序对照——确认你理解了"一步"里发生的四件事。

## 一步里的固定顺序（背下来）

① 草生长（有水才长；草<80 时 +2，≥80 只 +0.5）→ ② 动物吃草（每只动物吃 0.8）→ ③ 动物增减（草>50 +2；草<20 −3；否则不变）→ ④ 水分（+下雨档位 −动物×0.3）

## 手算对照表（从默认 60/20/50 开始，走 3 步）

| 步 | 手算过程 | 应得到：草/动物/水 |
|---|---|---|
| 1 | 草 60+2=62 → 吃 20×0.8=16 → 62−16=46；草 46 不变动物；水 50+3−20×0.3=50+3−6 | **46 / 20 / 47** |
| 2 | 草 46+2=48 → 48−16=32；动物不变；水 47+3−6=44 | **32 / 20 / 44** |
| 3 | 草 32+2=34 → 34−16=18；草 18<20 → 动物 20−3=17；水 44+3−6=41 | **18 / 17 / 41** |
