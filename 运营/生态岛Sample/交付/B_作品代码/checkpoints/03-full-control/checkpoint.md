# 第 3 关：全部解锁（完整控制与记录）

文件：`eco-island.html`。全部功能解锁——这就是参考版的完整能力。

## 本关目标

跑完一场 60 步的完整实验，学会用【开始/暂停/下雨档位】做"改变一个条件"的对照，并把结果讲出来。

## 建议做三个实验

1. **默认实验**：直接【▶️ 开始】跑完 60 步 → 观察动物结局（提示：会接近灭绝）、水和草怎么变
2. **对照实验 A**：【🔄 重来】后把初始动物滑杆调到 5，再跑 60 步 → 动物还灭绝吗？草呢？
3. **对照实验 B**：重来，把"下雨快慢"改成⛈️大雨，跑 60 步 → 和默认实验比，水一直满吗？动物呢？

每个实验注意看 **📔 小岛日记**——它会把关键事件翻译成人话，写实验记录直接抄它。

## 自查

- [ ] 三个实验都跑完了，每个都记下"第 60 步：草/动物/水"
- [ ] 能说出三个实验哪里不一样、为什么
- [ ] 知道跑得快慢（🐢/🚶/🐇）不改变任何结果（试一次：同一局面用不同速度走一步，数值一样）
- [ ] 知道改滑杆必须按【🔄 重来】才生效；下雨档位要暂停才能改
- [ ] 能对照 `reference/eco-island.html` 检查自己的观察没有错
