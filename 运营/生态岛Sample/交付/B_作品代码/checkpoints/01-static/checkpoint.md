# 第 1 关：认识小岛（静态状态）

文件：`eco-island.html`（直接双击用浏览器打开即可）

## 本关目标

打开程序，找到并看清模拟开始前的"第 0 步"世界。

## 你应该能看到

- [ ] 标题"🏝️ 生态岛：小岛为什么变了？"
- [ ] 小岛场景：太阳 ☀️、两朵云、三层草山、池塘 💧、蹦跳的 🐰
- [ ] 兔子角标显示 🐰 × 20
- [ ] 三张数值卡：草 60（绿）/ 小动物 20（橙）/ 水 50（蓝），各有进度条
- [ ] "⏱️ 第 0 步 / 共 60 步"
- [ ] 小岛日记已写了两行（重新开始的记录）
- [ ] 四个按钮是灰的（本关不解锁运行）

## 和参考版（最终版）的差异

| 项 | 参考版 | 本关 |
|---|---|---|
| 四个操作按钮 | 可用 | 全部禁用（灰色） |
| 速度/下雨下拉框 | 可用 | 禁用 |
| 其余（画面/数值/滑杆显示） | 相同 | 相同 |

## 完成标准

能指着画面说出："草、动物、水三个数是多少；哪里显示当前是第几步"——然后进入第 2 关。
