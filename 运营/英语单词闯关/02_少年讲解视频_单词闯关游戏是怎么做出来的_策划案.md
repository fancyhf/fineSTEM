# 少年讲解视频 · 策划案 v3 ——「拆开一个单词游戏，学会编程的六个概念」

> **状态**：策划案 v3（2026-08-31 三修）。v3 依运营指令：时长扩为 **5–10 分钟**（2 分钟讲不全课程）；内容定为**零基础编程概念科普 + 算法如何规划 + 如何用 AI 编程**——面对一个完全不懂编程的小孩，空白起步，一条视频学会基本概念；讲法对标 BBC 科普。
> **不绑定具体项目**：概念链、画面分轨、发布框架可复用到后续任何学员项目。
> **素材基线**：用现成项目，**不做新的儿童动画 web**。

## 一、一句话定位

**给 12–15 岁少年的一条 5–10 分钟讲解片：从一个「题目从哪儿来」的好奇出发，用真实的单词闯关游戏，把编程的六个基本概念（程序、数据、变量、算法、判断与循环、保存）一次讲通，最后讲清楚 AI 是怎么帮忙把想法变成工具的。**

| 参数 | 值 |
|------|-----|
| 受众 | 12–15 岁少年（初中，零编程基础），家长可旁听 |
| 成片时长 | **5–10 分钟**；台词约 2,600 字 |
| 画幅 | 16:9 横版（B 站 / Know 频道），可裁 9:16 竖版分发 |
| 形态 | 单人旁白 + 真实录屏 + 讲解卡插片；**非真人出镜、无卡通吉祥物** |

## 二、概念链（零基础起步的顺序）

BBC 式讲法：每一段都从现象或问题进，概念跟着画面长出来；禁灌输式定义起手，禁知识点清单式罗列。

| 段 | 概念 | 从哪里长出来 |
|----|------|-------------|
| 1 | 问题 | 现象：每轮十道题、顺序每次不同——这些题目从哪里来？ |
| 2 | 程序 = 指令清单 | 教机器人做三明治：写多清楚就做多准确；按下「开始」后指令依次执行 |
| 3 | 数据 = 材料 | 词库一百个词：每张卡片一个「对象」，一排卡片一个「列表」；菜谱与食材 |
| 4 | 变量 = 会变的盒子 | 分数、等级、经验条读的就是盒子里的数 |
| 5 | 算法 = 规划好的步骤 | 核心段：随便抓的两个漏洞（重复、偏心）→ 洗牌（从尾往前逐张交换）→ 干扰项取真实释义 → 十题顺序再洗；算法 = 明确目标 → 设计公平过程 → 检查漏洞 |
| 6 | 判断与循环 | 对错两条路（答对加分、答错进本子）；出题四步重复十次 |
| 7 | 保存 | 关页面重开进度还在：浏览器的一小块存放地，读回来接着用 |
| 8 | AI 工作台与导师模式（fineSTEM 实录演示） | 「不是手敲出来的」→ AI 工作台：左侧导师对话（大白话选题、开题、五步分步计划），右侧代码编辑器逐步写入；每步先讲「做什么/怎么做/为什么」；真实 Debug 事故（按钮全无反应→控制台红字→第 312 行多一个字符）由导师带着排查；落点：AI 不只代写，更带你看见问题 |
| 9 | 收尾 | 六概念回放 + 人机分工（AI 出速度，人管想清楚/查结果/说明白）+ 回家改词库 |
| 9 | 收尾 | 六个概念回放；回家改词库，第一个自己的工具 |

**AI 编程的立意（运营指定）**：观众记住的是「AI 能帮人把想法变成学习工具」+「想法、检查、说明白是人的部分」——不是平台广告，无平台名、无广告句。

叙事主角：默认「一位初中学生的真实项目」，不出镜、不指名；实名/出镜需账号主人确认。

**台词稿**：`03_少年讲解视频_台词稿_v5.md`（实测约 2,660 字 ≈ 9–10 分钟，已按本策划案与口语化规范 v3.1 写毕）。
