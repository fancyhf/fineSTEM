# 少年讲解视频 · 录屏与拍摄脚本 ——按旁白实测时长对齐

> **状态**：v1（2026-08-31）。旁白轨已合成（`素材/少年配音/`，Ethan，全片 **7.4 分钟**，逐段实测时长见下表）；剪辑时**画面向旁白对齐**，不是反过来。
> **拍摄环境纪律**：关闭微信/系统通知；OBS 1920×1080、30fps；保留鼠标轨迹（真实感）；游戏录屏前**清空 localStorage**（F12 → Application → Local Storage → 清除）保证「新玩家状态」。
> **素材文件**：游戏 = `素材/单词闯关_可运行版.html`（已验证可运行、已修正「学习」字形）；代码 = 同一文件在 VS Code 打开；AI 工作台 = `http://localhost:5184`（前端与 ZeroClaw 已验证运行）。

## 逐段拍摄单（时长 = 旁白实测）

### 第 1 段 · 一个问题（**24.2s**）
- 0–8s：双击打开 `单词闯关_可运行版.html`，首页完整入镜（Lv.1、开始测试）
- 8–16s：点「开始测试」，连答 1 题选择题（用键盘 1–4 更利落）
- 16–24s：快切：第二轮第一题与第一轮不同词（体现「顺序都不一样」）；定格一道题目
- 拍两条备用：任何操作失误即重录本段，本段只有 24 秒

### 第 2 段 · 程序 = 指令清单（**52.6s**）
- 0–20s：**讲解卡 A**「便签清单」逐条划勾动效（自制，见讲解卡清单）
- 20–40s：VS Code 打开游戏文件，滚动到 `<script>` 区：先指 startQuiz()（点开始后执行），再扫过 checkAnswer()
- 40–52s：回到游戏：点「开始测试」→ 出题 → 答题 → 结算弹窗，一条连贯操作（对应「指令依次执行」）

### 第 3 段 · 数据 = 词库卡片（**41.4s**）
- 0–18s：**讲解卡 B**「一排卡片」：抽一张翻转（正面英文/背面中文），标注「对象」；镜头拉远标「列表」
- 18–30s：VS Code：定位 `const WORD_BANK`，选中第一行 `{en:"accept",zh:"接受"}` 高亮
- 30–41s：滚动整段词库（100 行快速滚过），停在随机一处

### 第 4 段 · 变量 = 会变的盒子（**44.9s**）
- 0–18s：**讲解卡 C**「贴标签的盒子」：经验值盒子数字 +10 跳动，旁边经验条同步变长
- 18–35s：游戏实录：连答 2 题选择题，特写顶部经验条从 0 到 20、火焰徽章
- 35–45s：VS Code：`state.xp`、`addXP` 高亮两处（盒子在代码里的真身）

### 第 5 段 · 算法 = 公平抽词（**83.6s** · 核心段，重点制作）
- 0–25s：**讲解卡 D**「随便抓的两个漏洞」：同一张卡被抓两次（第 1 题与第 5 题撞词）定格标红
- 25–50s：**讲解卡 E**「洗牌动画」：词卡从队尾逐张与前面随机一张交换（两轮循环），然后前端抽出十张
- 50–68s：游戏实录：开始一轮，截取一道选择题完整选项（四个真实释义）；再开第二轮，同一词的选项组合不同（干扰项随机）
- 68–83s：**讲解卡 F**「算法三步」：明确目标 → 设计公平过程 → 检查漏洞，逐条点亮
- 备注：本段动画量最大，是全片制作重心

### 第 6 段 · 判断与循环（**45.6s**）
- 0–12s：**讲解卡 G**「岔路」：答案比对 → 对/错两条路分岔动效
- 12–30s：游戏实录：故意答错 1 题（单词进错词本），再答对 1 题（+10 分）——一错一对完整拍下
- 30–45s：切「错词本」页面展示刚进的词（红点在）；**讲解卡 H** 循环圈转 4 步 ×10

### 第 7 段 · 保存（**35.2s** · 一条连续镜头，不可剪辑造假）
- 完整连续拍：答 2 题 → 关闭浏览器标签页 → 重新打开文件 → 首页经验条/正确率保持
- 结尾：F12 → Application → Local Storage → 展开键值文本特写 2 秒

### 第 8 段 · AI 工作台与导师模式（**77.8s**）
- 0–12s：localhost:5184 登录 → Create 页全貌：左对话流、右代码编辑器
- 12–30s：回放真实项目的导师对话（项目 8a7c155e）：初三/阅读/单词工具的选题卡片、开题报告、五步分步计划（滚动展示，不必逐字停留）
- 30–45s：讲解式教学一条实录：导师「做什么/怎么做/为什么」的 Step 讲解 + 代码写入右侧编辑器
- 45–70s：**Debug 事故还原（预制备份文件）**：复制一份可运行版，在 `renderWrongBook()` 结束的 `}` 后插入一行 `]]>`（历史真实事故）→ 打开页面，所有按钮点不动 → F12 控制台红字 `SyntaxError` 定格 → 删除该行 → 按钮恢复
- 70–78s：回到对话流，导师回复「修好了」的确认画面
- ⚠️ 复现副本单独存放（如 `素材/_bug复现.html`），与正式素材文件严格分开

### 第 9 段 · 收尾（**39.5s**）
- 0–15s：**讲解卡 I** 六个概念图标依次点亮（指令/数据/变量/算法/判断循环/保存）
- 15–30s：VS Code：光标落在 WORD_BANK，把其中 3 个词改成常见中考词（实敲，不加速）
- 30–39.5s：刷新游戏页面展示修改生效；结尾停在首页「开始测试」按钮 1 秒

## 讲解卡清单（A–I，自制动效物料，本片主要工作量）

| 卡 | 内容 | 动效要求 |
|----|------|---------|
| A 便签清单 | 指令逐条执行 | 划勾逐条出现 |
| B 卡片排 | 对象/列表 | 抽卡翻转、镜头拉远 |
| C 变量盒子 | 盒子+标签 | 数字跳动、联动经验条 |
| D 随便抓的漏洞 | 撞词/偏心 | 撞词定格标红（唯一朱砂处） |
| E 洗牌 | 队尾逐张交换 | 必须真「动」，两轮循环 |
| F 算法三步 | 目标→过程→检查 | 逐条点亮 |
| G 岔路 | 判断 | 对/错分岔 |
| H 循环圈 | 四步×10 | 圈转+计数 |
| I 六概念回放 | 全片回顾 | 图标依次点亮 |
