```---
### 🧱 第一部分：HTML 结构（页面的「骨架」）
```
body
├── header              ← 顶部状态栏（始终可见）
│   ├── 等级徽章 Lv.1
│   ├── 经验条（进度条）

└── nav.navbar          ← 底部导航栏（固定定位）
```**设计思路**：三个视图**同时存在于 HTML 中**，通过 CSS 的 `.view--active` 类来切换显示/隐藏。这样做的好处是不需要来回创建销毁 DOM，切换速度极快。
---
### 🎨 第二部分：CSS 讲解（游戏化视觉的灵魂）
| 技术点 | 代码位置 | 为什么这样写 |
|--------|---------|-------------|
| **CSS 变量** | `:root { --purple: #7b2ff7; . }` | 所有颜色定义在一处，后续想换主题色只改这里，不用满文件搜索替换 |
| **渐变文字** | `.home__hero-title` 用 `background-clip: text` | 普通 `color` 只能是纯色，这个技巧让文字呈现紫金渐变色，视觉冲击力强 |
| **浮动画** | `@keyframes float` 给 📚 图标 | 3 秒一个循环，上下浮动 14px，让页面"活"起来而不是死板摆放 |
| **火焰脉冲** | `@keyframes flamePulse` 给连击🔥 | `scale(1.25)` 缩放呼吸效果，连击时才有，产生"燃起来了"的感觉 |
| **淡入动画** | `@keyframes fadeIn` 视图切换时触发 | 每切一个视图，内容从下方 12px 淡入滑上来，过渡自然 |
| **Grid 布局** | `.home__stats` 用 `grid-template-columns: repeat(3, 1fr)` | 今日统计三个卡片自动三等分，比 flex 更简洁 |
| **backdrop-filter** | header / navbar 用 `blur(12px)` | 毛玻璃效果——内容滚动时能隐约透出下层，有层次感 |
| **sticky 定位** | header 用 `position: sticky; top: 0` | 顶部状态栏滚动时始终可见，学生随时能看到自己的等级和经验 |

```### 2.3 干扰项生成算法
## 代码解读：三个核心算法
**① Fisher-Yates 洗牌** — 从数组末尾往前，随机选位置交换。这是「公平洗牌」的标准解法，每个排列出现概率相等。
**② 干扰项生成** — `getRandomDistractors("发现", 3)` 会从词库里捞出 99 个中文释义（排除「发现」），随机选 3 个。所以 `discover` 的干扰项可能抽到「依赖」「可用的」「独立的」——它们都是真实释义，看起来像正确答案。
**③ 混合生成** — `generateQuiz(10)` 先洗牌 → 取 10 个词 → 前 6 个做选择、后 4 个做拼写 → 最后整体再洗一次。**为什么最后要再洗？** 否则前 6 道全是选择、后 4 道全是拼写，学生会猜到规律。
```
