# 家长口播视频 · 制作规范

> 适用范围：本 IP 所有「家长口播短视频」——真人出镜（或固定机位）、竖屏、≤120 秒、讲给大人听。
> 本规范独立自包含，后续制作只读此一篇即可，不引用其他文档。
> 本规范不绑定任何具体主题：无论讲通识教养、STEM&AI、还是多元升学，都按此标准执行。文中以「[主题]」代表当集具体主题（观点 / 经验 / 科普 皆可）。

## 一、定位与边界

- 受众：家长（城市中产、关注教育与成长的成年人）。
- 讲「内容本身」：把一个主题讲给家长听——观点、经验、科普皆可（如一条升学决策逻辑、一段自鸡经历、一个自然或社会现象），帮他们构建认知与判断。
- 不是：不介绍「谁怎么教」、不刷题辅导、不重讲课本、不焦虑营销、不与任何人对立。
- 与另外两类成人内容区分：
  - 家长播客视频：双人对谈、22–26 分钟、三栏画面，做深度沉淀；口播是单人钩子，不做长。
  - 儿童视频 / 儿童 web：给孩子看的，口播是给大人看的。

## 二、策划规范

- 选题：通识教养 / STEM&AI / 多元升学 三域任一；从一个真实可感的生活切口进。
- 结构（≤120 秒）：
  1. 人话钩子（先抛一个生活画面 / 一句共鸣，不先甩数据）。
  2. 情境展开（把主题放进生活里）。
  3. 实质内容（讲清「它到底是什么」，不是罗列知识点）。
  4. 平静收尾（陈述句收，不喊口号、不提问、不悬念）。
- 数据后置为证据：数据 / 年份 / 人名落在完整陈述句里，作事实证据，不切碎、不前置当钩子。
- 数字独立成句：数字在完整流畅中文句内作事实陈述，不堆成「人名。人名。」式电报体。

## 三、画面规范

> ⚠️ **本节只规范视频内画面**。封面是平台物料（抖音 / 小红书 / 视频号），其尺寸、配色、版式、字号均**不套用本节**——封面按封面自身的标准执行。

- 竖屏 1080×1920。
- 米白纸底 `#F5F0E8`、墨色字、朱砂 `#C0392B` 只做「指针」标记当前主体，同屏不出现第二处红。
- 真人出镜：背景简洁、不抢戏；主体靠中上，避开平台遮挡区。
- 大字号、单帧文字少而精；留白 ≥ 55%。
- 拒绝：黑背景、PPT / Excel 标准化风、渐变字、发光字、红黄描边、粒子、扫光、3D 翻转。

## 四、台词规范

- 完整口语化句子，像城市中小知识分子妈妈跟朋友讲一个发现；有「我」的视角、带判断与温度，不播报、不地摊。
- 陈述事实如纪录片：数字独立成句、不加结论、不加比喻、不总结。
- 禁：焦虑营销词（破防 / 逆袭 / 捡漏 / 性价比 / 内卷等）、第二人称「你」指认、反问 / 悬念结尾、电报体碎句、口号式结论。
- 收尾：自然收住，不喊话、不诺下期。

## 五、制作与验收

- 配音实测时长驱动时间轴（不靠帧估算）。
- 自测清单：定位是讲内容本身？钩子是人话非数据？数字在完整句？画面米白非黑底？台词无「你」无焦虑词？收尾平静？
