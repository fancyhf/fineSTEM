> **版本**：v1（2026-09-01）。来源：家长播客（13 分钟竖屏）+ 少年讲解（7 分钟横屏）两支成片的全流程实证。
> **性质**：生产线工程经验（区别于内容规范——《有声稿口语化_规范》等管「写」，本文管「做」）。
> **回填状态**：封面大字报规则已回填《封面制作_规范》（模型 F）；逐轮 TTS/BGM/确定性渲染纪律已回填《家长播客_规范》制作备注；儿童视频规范已加生产线指针。
> **核心资产**：确定性渲染管线。建立后改稿/换声/换版式 = 分钟级迭代，本次全部返工都发生在管线建立之前。

## 一、生产线架构（已验证可复用）

```
台词稿（md，含分节/分轮标记）
  → 逐句/逐轮 TTS 合成（百炼 qwen-tts，实测每句时长）
  → sent_timeline.json（精确时间戳）
  → 确定性 HTML 舞台（所有画面状态 = 时间 T 的纯函数）
  → Playwright 逐帧截图（24fps，jpeg q80）
  → ffmpeg 合成 + 混音（apad 对齐时长）
  → 成片
```

- **换声/改稿重出**：一条命令，10-18 分钟/轮（竖屏 13 分钟片 19,000 帧 ≈ 18 分钟）。
- **渲染必须后台跑**，脚本要支持断点续渲（按已存在帧跳过）。
- **音画同步验证**：`silencedetect` 提取语音起点与时间轴比对，恒定偏移 ≤0.2s = 合格（字幕恒定超前 0.2s 是广播惯例）。

## 二、代价最大的三个教训（都是返工实证）

1. **规格错 = 全链返工**。少年视频时长先后定错两次（10 分钟 → 90 秒 → 5-10 分钟），每次错都要重写台词、重配音、重渲。**纪律：时长/画幅/平台三要素开工前与运营书面确认，写进策划案头部。**
2. **字幕时间禁止按字数比例估算**。TTS 语速不均匀，比例估算的字幕在段内必然漂移，用户会听出来。**纪律：逐句合成 + ffprobe 实测每句时长 + 精确时间戳驱动字幕。**
3. **事实错误在配音后才发现 = 重配重渲**。词库实数 108 写成「一百个」「九十九个干扰项」，配音后核对代码才发现。**纪律：写稿时对照成品逐项核数，配音前最后一遍事实清单。**

## 三、TTS 语音（百炼 qwen-tts）

- **音色**：预置音色稳定可用（Cherry=知性主持、Chelsie=清透嘉宾、Ethan=少年旁白）；第一版合成 pad 式 BGM 被否（嗡嗡声），换「有节拍/琶音/贝斯」的短衰减音乐合成才通过。
- **限流**：429 Throttling 常见，重试退避 3+a×4 秒可扛；请求间隔 ≥0.25s。
- **单次请求 ≤100 字**：超长句尾能量衰减。
- **数字/单位按读法写全**（一百零八个，不写 108）；外文词加读音注；emoji 在 PIL/PPT 字体里是豆腐块。
- **语速**：旁白 Ethan 308 字/分偏快、播客对谈 1.08x atempo 校正到 ~13 分钟；atempo 对时间轴做统一缩放即可，音画同步不破坏。

## 四、音频工程坑（全踩过）

- **ffmpeg concat demuxer 混编 wav/mp3 会静默丢静音条目**（时长对不上、无报错提示）→ 用 **wave 模块 PCM 层拼接** 或 filter_complex concat。
- amix `duration=first` 跟随第一条输入；片尾要 BGM 就 `duration=longest` + 输出 `-t` 封顶。
- 有音轨 ≠ 有声音：**每段混音后必跑 volumedetect**（合格线 max ≥ -6dB）。
- BGM 纪律：音量 9-13%、首尾淡入淡出、**宁空勿噪**（合成 pad 类持续长音 = 嗡嗡声，一刀禁绝）。

## 五、确定性渲染纪律（HTML 舞台）

- **所有画面状态 = 时间 T 的纯函数**。状态式动画（opacity 向目标收敛之类）在逐帧渲染下会卡在中间值——淡出永不发生、叠影就是这么来的。
- 帧步进渲染时注意**真实时间依赖**：游戏内 1.5s 自动跳题等 setTimeout 会按真实时间走，检查点动作之间留足场景时间。
- **代指悬空、CSS 三参 translate（非法）**等低级错都会全屏白板——先小样探针再全量渲染。
- iframe 内嵌真实应用（file:// + --allow-file-access-from-files）可脚本化点击，录屏素材无需人工操作。

## 六、平台机制（fineSTEM / Know）

- **Know 首页主位**由 `content/know/index.json` 的 `featured` 决定——不换主位，新内容「看得见数据、看不见版面」。
- **栏目口径**：`categories.ts` 的 `episodesOfCategory` 决定归属；「儿童互动视频」是动态口径（互动演示/儿童观众），新系列要显式纳入需改判定函数。
- **Know 节目对外链接一律指向公开页面**（灵感墙卡片页），项目详情页（/research/projects）要登录，访客点了就是空白。
- **MarkdownText 不渲染 Markdown 链接**（[文字](网址) 显示为纯文本）——已加 URL 自动链接；视频入口用**卡片块**（缩略图+播放键，点击进节目主页），不放裸链接。
- 演示卡淡入淡出等动画若用「逐帧向目标收敛」写法，帧步进下会卡死中间值——一律改纯函数。

## 七、发布侧

- B 站标题以**上传者实际填写**为准，与发布文案不一致属常态，不必强求。
- 章节时间轴必须按**最终成片实际时长**生成（任何提速/剪辑后重算）。
- 封面（教育类）：**文字主体占 70%、3-7 字关键词最大字号、3-4 级字重层次、浅底高对比、拼贴笔记材质（拍立得/胶带/便签/红笔圈）**；场景插画+对称小标题 = PPT 感，必被否。emoji 在 PIL 字体里是豆腐块，用 ①②③ 代替。

## 八、成本账（实际）

- 旁白 TTS：全片多轮迭代 ≈ 个位数人民币。
- 渲染：竖屏 13 分钟片 ≈ 18 分钟机器时间；横屏 7 分钟片 ≈ 10 分钟。
- 人工操作：0（除最终看片验收）。
