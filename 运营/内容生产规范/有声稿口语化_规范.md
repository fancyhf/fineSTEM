# 有声稿口语化 · 规范（口播 / 播客 / 讲解视频台词通用）

> **版本**：v3.1（2026-08-31 二修）。v1 解决书面腔；v2 解决北方腔与代指；v3 解决三不像腔调、广告式提品、说教灌输；**v3.1 新增「句子完整性铁律」**——问答的答句必须复述主语、过渡必须是完整句、功能词（是/要/会/就/把）一律不省略。依据运营审查实例：「看完，是读。」「不止一样。」「有一回问我……」等省略句，转音频后听众无法切音识词。
> **适用范围**：本 IP 一切要念出声的稿子——家长口播、家长播客、儿童视频、少年讲解视频。
> **听感目标**：标准普通话、克制、现代、面向一线大城市。对标 BBC 纪录片解说、英美顶级 STEM 频道、南方顶级谈话节目。

---

## 一、广播语言和书面语的根本差异

| | 书面（书刊 / 图文） | 有声（广播 / 播客 / 台词） |
|---|---|---|
| 接收 | 眼睛，可回读、可停顿 | 耳朵，**过耳不回**，只有一次机会 |
| 句子 | 可以长、可以套、可以倒装 | 一句一口气；一个从句包一个想法 |
| 词汇 | 允许书面词、文言字、缩略 | 只用「说出口的话」；说不出口的就不要写 |
| 冗余 | 冗余是缺点，删 | 适当的重复与路标是特性——听众需要被提醒 |

判据（NYT 广播写作课原话改）：**这句话你说给朋友听时会这么讲吗？不会，就重写。**

## 二、句子完整性铁律（v3.1 新增，最高优先级）

**音频不是不许精炼，而是不许省略。** 废话不要，但每一个分句的语法必须齐全——听众靠声波切分词句，省略一两个字，切分就失败。

1. **超短过渡句全禁。** ✗「看完，是读。」「最后一件，背单词。」——文不文白不白，音频里不知所云。→ ✓「看的这一部分结束了。第二件事情，是阅读。」「最后一件事情，是背单词。」
2. **答句必须复述主语。** 被问「他学到了什么？」，答句必须以「他」开头重新交代：✗「不止一样。」→ ✓「他学到的东西不止一样。」。只有纯粹的应答词（对、好的、是的）允许单独成句。
3. **每个分句都要有主语。** 叙事推进时，换了动作主体必须重新点名：✗「有一回问我，企鹅怎么讲。」→ ✓「有一回，孩子问我，企鹅用英文要怎么讲。」
4. **功能词一律不省**：是 / 要 / 会 / 就 / 把——「听力和口语弱一些」→「听力和口语要弱一些」；「答对了加分」→「答对了就会加分」。这些字在书面上可省，在声音里就是词与词的胶水。
5. **不缩写、不抽象**：数字写全读法；机构名、缩写首次出现给全称。
6. 广播允许的自然省略只剩一种：连续同一主语做连续动作时，后半句可承前省（「他打开文件，改了十个词」）——但一换主体就必须重新点名。

## 三、音频清晰度纪律（代指与句子）

1. **开篇禁止用代词起句**（「先看它玩起来」→听众不知道「它」是谁）。第一句必须点名本体。
2. **每个代词的先行词必须在同一句或紧邻上一句里出现过**；跨句回指一律换成名词。
3. **主谓宾齐全，按完整句写**。减缩语全禁：定题型→确定题型；存进度→保存进度；加经验→获得经验值。
4. **名词要容易懂**。术语出现前先给大白话；裸术语（不明觉厉词）禁入稿。
5. **隐喻必须先落本体，再给喻体动作**。✗「连着三天，它就开始烧」→ ✓「页面上方有一团火苗。火苗代表连续学习的天数。连续三天，火苗就会烧起来。」
6. **同音歧义检查**：全部/全不、因而/因——可能听错的搭配换词。

## 四、词汇与句法（承 v1）

1. 一句一个意思，一口气念完；句长 10–20 字为主，上限 25 字。
2. 主语在前，不用长定语开头。
3. 书面词 / 文言单音节字全禁：即、次日、若、均、亦、故、其（物主）……
4. **数字、行号、序号按读法写全**（「一百个」不写「100个」）。
5. 外文词首次出现给读音注与一句人话解释。
6. 路标显性化 + 关键信息复述。

## 五、地域腔调禁令（承 v2）

**全禁北方 / 东北 / 相声 / 段子 / 二人转的词汇与节奏。** 受众是一线精英家庭，方言腔 = 土气 = 不专业。

- **禁用词表（不限于）**：咱们、哟、哎哟、得嘞、对喽、嘎哈、咋、啥、整（动词）、鼓捣、抓瞎、抖包袱、你猜怎么着、扎心、支一招、交个底、翘尾巴、带沟里、唠、侃、贫、老……了（程度）、贼（程度）、倍儿。
- **禁节奏**：铺垫—抖机灵—等笑声的段子节奏；贯口式排比；自我捧逗。
- **允许的幽默**：克制的自嘲、事实反差、轻描淡写（英式 dry）。

## 六、三不像腔调禁令（承 v3）

**文白混合、半文半白、伪文艺金句、内地文学腔——全禁。**

- **禁用句式与表达（不限于）**：伪金句俗喻（「那层窗户纸」「捅破了天」）；模糊动词单独作抽象动作（「这个问题藏得住」→「这个问题不容易被发现」）；四字短语堆砌（「读写听说」→拆成完整句）；老式文艺腔（「泡在水里」「下了水就会湿」）。
- **判别法**：念给一个 90 后一线城市白领听，觉得「老气 / 绕 / 怪」就重写。
- **正确方向**：现代白话、具体、直接、完整句。

## 七、人称与视角（承 v2）

1. **讲解 / 口播**：以无主语句和「我们」为主。第二人称「你」每百字不超过一次，且仅用于操作性指令。
2. **对谈播客**：主持与嘉宾之间的「你」是角色对话，不受第 1 条限制，但不许堆叠成口头禅。
3. 禁对听众的指认式称呼（「家长们」「小朋友们」「各位妈妈」）。

## 八、产品 / 项目 / 平台提法规矩（承 v3）

**我们不是在打广告。**

- **禁**：「它不是大公司的产品」「它的作者是一位初中学生」「在一个叫 fineSTEM 的编程学习平台上」。
- **正确提法规**：把能力和本质先讲出来（孩子用 AI 辅助做了一个背单词的小工具；AI 还能帮人做开发）；必须提名字时一句带过，不做身份对比、不做「不是 X 是 Y」式宣传。
- **内容优先**：观众记住「AI 能做学习工具」，名字是副产物。

## 九、说教与灌输禁令（承 v3，儿童 / 少年讲解尤甚）

**我们不是教学机，我们是启发者。**

- **禁**：「任何一个网页，都由三个部分组成」「记住以下几点」「我们来认识一下」——课堂灌输式。
- **正确做法**：从一个具体的画面 / 一个好奇的问题 / 一个反直觉的结果开始；原理是跟着画面走出来的。
- **知识密度**：按片长配平——90 秒只装一个核心发现；5–10 分钟的讲解片可以走完一条完整的概念链（现象 → 概念 → 概念 → 原理 → 动手），但仍禁知识点清单式罗列，每个概念必须带着画面出场。

## 十、对谈播客加强项

1. 允许碎句与自我修正，但句子主干（主谓宾）始终完整；答句按 §二.2 复述主语。
2. 接话要复述对方关键词再展开，不用「嘿」「嚯」起手。
3. 禁论文连词：因此 / 然而 / 此外 → 所以 / 不过 / 还有。
4. 笑声、停顿写进稿子，不靠后期脑补。

## 十一、验收：朗读测试 + 完整性扫描（不过不算完稿）

- [ ] 出声读全稿：换气困难、舌头打绊、想回听的地方全部改写。
- [ ] **超短句扫描**：正文里凡 8 字以内且非应答词的句子，逐个检查是否语法齐全——不合格即重写。
- [ ] **答句扫描**：问答里每个内容性答句，是否复述了主语？
- [ ] **功能词扫描**：是 / 要 / 会 / 就 / 把 的省略为零？
- [ ] 开篇点本体？代指不悬空？数字为读法？
- [ ] 三不像句、北方腔禁词表为零？
- [ ] 产品/平台提法规矩？讲解稿「你」密度 ≤ 每百字一次？无说教灌输？
- [ ] 抽一段给目标听众听（真人或 TTS）：听得清、听得懂、不觉得土、不觉得在上课——四条全过才算过。

## 五、三不像腔调禁令（v3 新增，最高优先级）

**文白混合、半文半白、伪文艺金句、内地文学腔——全禁。** 这种表达既不是书面语（不精确），也不是口语（听不清），是最糟糕的第三种腔。听众第一反应是「这人在说啥」，第二反应是划走。

- **禁用句式与表达（不限于）**：
  - 伪金句俗喻：「那层窗户纸」「在岸上站了二十年」「把水搅浑」「捅破了天」——旧、土、文白夹杂，听着糊；换现代、具体、白话说透的表达。
  - 模糊动词：「藏得住」「摸得到」「够得着」作为抽象动作单独使用（「这个问题藏得住」→ 必改成大白话：「这个问题不容易被发现」）。
  - 四字短语堆砌：「读写听说」「听说读写」「稳扎稳打」「循序渐进」——全拆成完整句（「阅读能跟上，写作也不差，听力和口语就弱一些」）。
  - 老式文艺腔：「泡在水里」「下了水就会湿」——不是不能用比喻，是比喻必须先给本体再给喻体动作，且喻体要现代、要具体，不要老派文艺腔。
  - 「先说……再来说……」「我们来聊聊……」——广播腔起手，一律改成更自然的起法。
- **判别法**：把这句话念给一个 90 后一线城市白领听，看她会不会觉得「这话怎么这么老气/这么绕」。会，就重写。
- **正确方向**：现代白话、具体、直接、完整句。能说清楚的事，不绕弯子。

## 七、产品 / 项目 / 平台提法规矩（v3 新增）

**我们不是在打广告。** 项目和平台名出现的目的，是为了让内容有具体落点，不是为了宣传。每次提之前先问自己：不说名字行不行？不行才说。

- **禁**：「它不是大公司的产品」「它的作者是一位初中学生」「在一个叫 fineSTEM 的编程学习平台上」——这是广告片话术，不是内容片话术，且完全没必要。
- **正确提法规**：把平台能力和项目本质先讲出来（孩子用 AI 辅助做了一个背单词的小工具；AI 还能帮人做开发）；如果必须提名字，一句带过，不做身份对比、不做「不是 X 是 Y」式宣传。

## 八、说教与灌输禁令（v3 新增，儿童 / 少年讲解尤甚）
