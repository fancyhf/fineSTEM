# 鸡娃先自鸡 · 节目文案写作规范（口播 / 播客 / 视频脚本 / 配套动画通用）

> **版本**：v2（2026-08-23 迭代。v1 立基于 2026-08-22 配套A播客逐字稿纠偏实录；v2 增补：①"数字独立成句"正确定义与电报体禁令 ②配套C儿童动画制作标准 ③历史稿标杆/反面教材清单 ④约束前置纪律）
> **适用范围**：本IP所有口播文案、播客逐字稿、视频脚本、配套动画脚本。
> **使用方式**：本规范独立自包含，后续创作只读此一篇即可落地，无需回溯其他文档。

## 一、定位红线：节目是什么、不是什么

节目是「家长成长」内容——把数理思维、文史哲、人工智能、升学等**内容本身**讲给家长听，帮他们构建认知，再去跟孩子对话。

**不是：**
- 不是介绍"谁怎么教""哪家课好"（讲内容实质，不介绍教法）
- 不是刷题辅导、不是重讲课本、不是教 1+1=2（与衡水式高低端辅导划清界限，否则项目无意义）
- 不是焦虑营销、不是跟教培或任何人对立（项目初心是帮家长构建思维，不是制造对抗）

**容器定位（配套A播客）：** 它是整个IP旗下的「家长成长播客」，数学只是第一个系列。后续文史哲、人工智能、升学专题共用同一容器，不另起炉灶。主理人定位是IP整体播客主理人，**不得窄化为"数学思维播客主理人"**——否则其他专题无处安放、越做越乱。

---

## 二、最高标准：深入浅出

真正的高手，是深入浅出、有趣地讲明白。听众听完能「啊哈，原来就是这么回事」。最招人烦的，是把知识点罗列出来、用生动例子包装，本质仍是老师念书——听众被动接收、全程没抓住「它到底是什么」。

**验收标准（写好一段问自己）：** 这段讲完，读者/听众脑中能否「运行」一个具体动作？能，就是讲明白了；只记住一串形容词，就是没讲明白。

**死板念书风（反面）：** 罗列现象或例子暗示规律、回避概念命名与定义、把结论摆出来代替推导。
**丘成桐式（正面）：** 从现象出发 → 跟听众一起推「为什么」 → 让听众自己走到「啊哈，X 就是 Y」的定义性理解。

---

## 三、概念必须讲透（不是包装知识点）

这是最容易犯、也最致命的错。好内容不是「举了好多例子」，而是「让听众真的懂了那个概念」。

每个核心概念须同时具备：
1. **一句话大白话定义**——说清「它到底是什么」，不靠例子暗示。
2. **一个主导隐喻**——用具体可感的动作或画面承载定义，贯穿全篇。

**隐喻从对话自然长出：** 先让嘉宾试着概括（「所以它是……不用背，只要知道怎么长？」），主持人再确认升华（「你这句话刚好撞上一个核心东西，叫递推」）。不单方面宣布概念。

**隐喻库（已验证有效，可扩展）：**
- 递推 = 搭积木（第一层放 1 块，第二层放 1 块，从第三层起每层照「前两层加起来」放；不用知道第一百层长啥样，会这一个动作它就自己长出来）+ 爬楼梯（会迈一步、每步踩在刚迈那步上，多少级都上得去）
- 递归 = 俄罗斯套娃（最小的打开还是个同款娃娃、只是小一号；把大事拆成同款小事，拆到不能再拆答案自己出来）

**自检：** 写不出这个「动作 / 画面」，就是没讲透，重写。

---

## 四、开场须「起范儿」

播客 / 视频不是上来就砸题、甩概念。须先铺情境，把听众拽进生活，再自然落题。

**正确范式（吾皇亲定）：**
> 生活共情一句（「做小学生家长，遇到数学，一家人头疼啊。」）
> + 身边乐事 / 场景一句（「说个鸡娃群的乐事——」）
> → 钩子（「这串数其实哪儿都藏着——向日葵里、松果里、连手机里都有。」）
> → 今日聊什么
> → 自然请出嘉宾
> → 才抛题

**反面：** 「今天咱就拿一年级一道题，把背后的数学聊透。小雅，你看到 1, 1, 2, 3, 5, 8，下一个是谁？」——无前文、无铺垫，像念报告。

---

## 五、话术质感：都市白领高净值

主持人 / 口播要有「城市中产、小知识分子妈妈」的腔调——有「我」的视角、带判断和温度、克制有文化感，像跟懂行的朋友讲一个发现。对标丘成桐的大家气度，而非机构销售、非新闻播报、非地摊市井、非电报体。

**具体红线：**
- 不报嘉宾年龄（尤其女性）。背景放角色设定卡，正文不写「32 岁孩子刚上一年级」式相亲介绍。
- 不无中生有树敌：不把教培 / 机构当假想敌（「今天不聊教培那一套」「我们不报班」这类对立姿态纯属制造对抗，项目本就不是跟谁做对）。语气中性真实，不撇清、不表态。
- 禁一切干巴巴罗列，分三类点名：
  ① 抽象论断（「它几乎是这个世界的底层语法之一」）
  ② 「我举 N 个地方」式框架（裸列第一 / 第二 / 第三）
  ③ 名词短语并列式教学提纲（「递推怎么想、模式怎么认、一个问题怎么拆」——老师念课纲风，最忌）
- 每写一段台词，落笔前自检：**这句是「讲给他听」还是「带他看」？若是前者，重写。**

---

## 六、场景真实，不瞎编

家长 / 孩子的行为桥段必须符合现实，不得脱离生活编造。

- **真实场景**：孩子做找规律题不会 → 家长随便教 / 让看答案 / 随口说「你找找规律嘛」，家长自己也未必真懂。落点「教得不如今大师（没看见怎么长）」，而非虚构「让孩子背数列」之类桥段。
- **进入场景须直接呈现具体可感的生活瞬间**（第一 / 第三人称亲历），不得以「我讲个你会在 X 撞见的事」式预告空话代替——预告只表态「要讲场景」，听不到任何真实画面。
- **对孩子认知水平的设定须真实**：给一年级 / 7 岁孩子的表述，须符合其普遍理解力，不得借孩子之口写超龄的抽象或哲学归纳。给孩子的应是开放观察问句（「你猜它怎么长的」）或具体画面（「画一条小蛇一节节长出来」），而非公式化总结。

---

## 七、技术 / 事实必须准确，不瞎说

涉及数学、编程、人工智能等专业论断，落笔前先确认属实。**为生动编造错误关联，比文风问题更严重。**

**反面（真实踩坑）：** 「你相册能认出猫狗，那个模型本质上就是递推」——图像识别（卷积神经网络）并非递推结构，属事实错误，硬安因果。
**正面：** 导航算最短路线（把「到每个路口的距离」从起点一步步推到终点，每步站在前面算好的基础上）——最短路径算法本质是递推，准确且人人可感。

**原则：** 宁可换更准的例子，不可硬安错误因果。

---

## 八、内部策划 / 用户分析，不得口号式搬入内容

策划文档里的用户画像定性、项目定位口号、用户痛点二分法、「我们做这个的原因」式宣言——这些是**内部讨论素材，不是台词**。

节目里角色必须是真实的人在自然对话：感悟从前面具体讨论中自然流出，不得念策划文档、不得在结尾喊项目使命。

**收尾纪律：**
- 禁用「给小雅、也给听着的普通妈妈一句话」式点名对方 + 面向听众喊话（假到家的访谈形式）。
- 不得许诺未确定的下期 / 具体内容（系列未定型，「鬼知道下一期讲什么」——不许诺主题、不点名「各位」喊话）。
- 真实收尾：自然聊完，或回扣开场画面形成闭环。

---

## 九、可视化 / 动画联动（配套C）

概念要能「画」出来。口播里用的隐喻（小蛇一节节长、俄罗斯套娃、格子填数），直接是动画的镜头——文案与动画共享同一套具象语言，不重复创作。动画讲内容本身（可可爱爱非做题）。

---

## 十、执行纪律（写稿 Agent 必守）

1. **被批必当轮真改**：收到纠偏，立即读取原文 → 真实修改 → 通读验证；不得只承诺「已改」而文件未动。
2. **改结构不等于改文风**：文风顺了但概念锚点缺失，全文仍是念书风。纠偏时先诊断根因（是某一句？还是结构缺概念锚点？），再动手。
3. **主动思考，不填空**：策划要带判断与取舍，反对「点什么填什么」的填空式执行。
4. **约束前置，不当摆设**：红线（画面占比 / 数字表达 / 口吻 / 收尾）须写在文件头部、动手前就钉死，写完**逐条验**，不是写完总结"已通过"就交差。框架 / 惯性先行（如把视频中部默认给 60%、把"数字独立成句"默认当切碎）是反复翻车的总根——约束若只停留在"被记录"，等于没有约束。

## 十一、数字表达："独立成句"≠碎成电报（本轮补盲区）

「数字独立成句」是本项目反复强调的纪律，但**规范 v1 漏了它的正确定义**，导致 90 秒版、初稿版把它误解成"切碎成单词"，反而写出最傻的电报体。特此单列。

**正确含义**：数据 / 人名 / 年份作**事实陈述**，落在**完整流畅的陈述句**里，不叠加"因为所以"强行因果。

- ✅ 正确："2026 年 7 月，菲尔兹奖揭晓，王虹和邓煜同时获奖，这是中国籍第一次。"——数字在完整句中作事实，不破坏中文语法。
- ✅ 正确（数据后置）："动画电影《牛来》，成本不超二十万；票房从首日三千四，走到两千万。"——数据在陈述句内作证据，不切碎。

**错误（反面，点名禁项）**：把信息切碎成孤立单词 / 短句堆砌——

- ✗ "王虹。邓煜。菲尔兹奖。中国籍，第一次。"（地摊电报体，显低智文盲）
- ✗ "三位妈妈。一位乡镇英语教师。一位消化内科主任。六十后，从零学编剧。职业不同。一个共同点。"（名词短语并列式教学提纲，禁项③的变体）

**验收**：写完通读——每个数字 / 人名是否都在完整句内？是否有孤立"人名。人名。"碎句？有则合并为流畅陈述句。

**历史教训**：曾出现某稿"调性自检"把"王虹。邓煜。"标为"数字独立成句✓"——这是根因误解，严禁再犯。把"数字独立成句"当成"切碎"的，比不懂这条纪律更危险。

## 十二、动画制作标准（配套 C 儿童动画 · 搭积木版为模板）

配套 C 是给孩子看的"内容本身"动画（可可爱爱非做题），与配套 A（家长思维底座）**共享同一套具象隐喻语言**（搭积木 / 爬楼梯 / 小蛇 / 套娃），文案与动画不重复创作。

**画面构造 5 维法（缺一不可，否则 = PPT 课件）**：

1. **外框 frame**：开放上沿 + 开放两侧（只保留下边框做收边）+ 4 角朱砂云纹作画框暗示。**禁闭合 4 边**——侧竖线会穿越标题区 / 远景，出现"黑色短线穿出吉祥物下方"。
2. **远景层**：真实柔和色非墨色剪影——云 = 暖白 + 淡蓝灰描边、远山 = 淡青低饱和、草丛 = 竹绿；禁用墨色剪影（变"灰团"，既脏又违反"拒绝灰白配色"）。
3. **标题区装饰**：grid 3 列（吉祥物 / 居中标题卡通字 / 进度圆点）。吉祥物"动"用整体 bob + 眨眼，**禁外伸独立 hand 撞远景**（曾出现"云里冒红球"）。
4. **演示区辅助 UI**：贴士卡 + 惊喜气泡（`pointer-events:none`）；地平线手绘草石。
5. **底栏对话气泡**：漫画式双层三角尾巴 + 圆胖按钮。

**配色**：宣纸暖白底 `#F5EFE2`；中国色按数字染色（1 朱砂 / 2 石青 / 3 苔绿 / 4 藕荷 / 5 赭石……），**经 `:root` 变量单一来源，JS 用 `getComputedStyle` 读取，禁止硬编码 hex**；朱砂印章顶标（反白数字）悬空飘出块边缘，**禁压字**。

**字体**：卡通中文字体（ZCOOL QingKe HuangYou / ZCOOL KuaiLe，Google Fonts CDN，OFL 商用）。

**动效**：块长出 `spawn-pop` 弹跳；每 2.5–4s 随机眨眼；关键时刻 `surprise` 定格；全程"像活的"。

**交互复位**：重播按钮须真重置（清 DOM / 复位 `heights=[1,1]` / 进度点 / 气泡 opacity）；`refit` 算法测量真实底部倒推块尺寸，避免高塔挡标题。

**工程坑（已实证，跳过即重踩）**：绝对定位浮层须显式 `z-index`；标签悬空按 main 顶定位（非块顶）；frame 开放上沿须同步让 head 透明（否则天空空白）；多色块同框须拉色相避免糊。

## 附录：写稿自检清单（Checklist）

写完一篇口播 / 播客 / 脚本，逐条打钩：

- [ ] **定位**：是讲「内容本身」，不是介绍教法 / 刷题 / 重讲课本？
- [ ] **容器**：配套A是IP家长成长播客，主理人未窄化为「数学播客主理人」？
- [ ] **深入浅出**：每段核心概念，读者脑中能「运行」一个动作（有定义 + 有隐喻）？
- [ ] **开场**：有生活共情 + 场景钩子的「起范儿」前文，非直接砸题？
- [ ] **质感**：都市白领高净值，无报年龄、无树敌、无干巴巴罗列（抽象论断 / 我举N个 / 名词提纲）？
- [ ] **每句台词**：是「带他看」而非「讲给他听」？
- [ ] **场景**：家长 / 孩子行为真实，无瞎编；给孩子画面 / 问句，无超龄总结；无预告式空话？
- [ ] **技术 / 事实**：专业论断已确认准确，无硬安错误因果？
- [ ] **内部素材**：无用户画像 / 项目口号 / 使命宣言入台词？
- [ ] **收尾**：自然闭环，无点名喊话、无许诺未定下期？
- [ ] **动画联动**：概念隐喻与配套C动画共享同一套具象语言？
- [ ] **数字表达**：无"人名。人名。"式电报碎句？每个数字都在完整流畅陈述句中（非切碎成单词）？
- [ ] **动画画面**：配套C是否落实 5 维构造法（开放画框 / 真实远景 / 标题装饰 / 辅助UI / 对话气泡）？配色经 `:root` 单一来源、无硬编码 hex？
- [ ] **历史稿**：是否误引反面教材（90 秒版 / 初稿 / 兔子脚本）作参考？
