# 家长播客视频 · 制作规范

> 适用范围：本 IP 所有「家长播客视频」——竖屏三栏、双人对谈音频优先、讲给大人听、22–26 分钟。
> 独立自包含，后续制作只读此一篇。
> 不绑定具体主题：通识教养 / STEM&AI / 多元升学 任一主题都按此标准。文中「[主题]」代表当集具体主题。

## 一、定位与边界

- 受众：家长（城市中产、关注教育与成长的成年人）。
- 是视频，但符合「播客风」：音频双人对谈为主，画面是辅助——中间栏放一点画面，给有需要的家长来 get 知识。
- 从来不是真人出镜视频，也从来不是有人物形象（无卡通人物）的视频。双人对谈是「声音角色」，不是画面里出人。
- 讲「内容本身」：把主题讲透，不是介绍教法、不刷题、不焦虑营销。
- 与另外两类区分：
  - 家长口播：单人钩子、≤120 秒；播客是双人对谈、做深度。
  - 儿童视频 / 儿童 web：给孩子看的；播客是给大人看的，演示素材不共用。

## 二、策划规范

- 结构：开场 + 幕 1–5 + 收尾（约 22–26 分钟），按当集主题组织。
- 双人对谈：主持人带节奏、嘉宾展开；全程讲内容本身。
- 每核心概念须有：①一句话大白话定义 ②一个主导隐喻（具体可感的动作 / 画面，从对话自然长出，不单方面宣布）。
- 选题任意主题，不局限于某一域。

## 三、画面规范（三栏等高）

> ⚠️ **本节只规范视频内画面**。封面是平台物料（抖音 / 小红书 / 视频号），其尺寸、配色、版式、字号均**不套用本节**——封面按封面自身的标准执行。

- 竖屏 1080×1920。
- 三栏**等高**，每栏 = 全屏 1/3（约 640px）：
  - 顶栏 1/3：节目名 + 声波线（绑定音频，广播感）。
  - 中栏 1/3：演示面板在此栏内浮起，**≤ 栏内一半**，平时收起，仅讲概念时淡入淡出。
  - 底栏 1/3：大字体台词，铺满该栏（非 15% 条状、非色块）。
- 配色：暖深炭底 `#241F1B`、主文字暖象牙 `#ECE3D2`、嘉宾标签赭石金 `#C9A24B`、朱砂 `#C0392B` 只点睛。哑光、低饱和、手绘肌理，对标生活杂志。
- **非真人出镜、无卡通人物形象**：画面是文字 / 演示 / 抽象图形，不放人、不放卡通角色。
- 演示素材成人向、独立制作，不复用儿童视频 / web 的画面。

## 四、台词规范（双人对谈稿）

- 主持人 + 嘉宾双声线；开场「起范儿」：生活共情 + 场景钩子，再自然落题。
- 深入浅出：每段核心概念，听众脑中能「运行」一个动作（有定义 + 有隐喻）。
- 话术质感：城市中产、有「我」视角、克制有文化感；不报嘉宾年龄（尤其女性）、不无中生有树敌、禁干巴巴罗列（抽象论断 / 「我举 N 个」/ 名词提纲）。
- 禁：内部策划 / 用户画像 / 项目口号入台词；收尾点名喊话、诺未定下期。
- 收尾：自然闭环，回扣开场或自然聊完。

### 4.1 播客文风铁律（通用，[主题] 适配任意主题）

播客是「双人对谈的声音」，不是稿子念出来的。AI 写播客最易翻车的根因：把策划案的「清单梗概体」（"X → Y → Z"）直接展开成念稿体。以下为通用文风纪律，任一主题（数理 / 文史 / AI / 升学）都适用，不绑定具体领域：

1. **口语聊天体，不是播报体 / 念稿体 / 清单体。** 用语气词、碎句、自我修正、停顿（"就比如说——""蒙圈过""真是的"），像真人在聊，不像在念方案。把策划清单（如"向日葵 34/55、松果 8/13、菠萝 8/13/21"）打散进对话，由人物自然数出来，不裸列。
2. **动作驱动的文字（"看见怎么长"的文字版）。** 动词全是身体动作或可感变化：掰开、盯着看半天、踩在刚迈的那一步上、一节一节长出来、拆开还是个娃娃、一格格填。文字本身要能「运行」一个动作，不靠形容词堆。
3. **设问—解惑的对谈节奏（骨架）。** 每段是一个小循环：嘉宾抛真实困惑 → 主持接住 → 引出概念 → 嘉宾恍然。靠"疑问—解答—啊哈"推进，不是文章的直线叙述。困惑须是普通家长的真实反应，不为抛概念硬设弱智问。
4. **比喻先于定义（呈现次序）。** 每个硬概念先用动作比喻（[主题] 皆然：递推 = 搭积木、递归 = 套娃），最后才轻点术语。绝不开头扔定义、绝不"我们来认识 X"。与第二节"须有定义 + 隐喻"互补：那里管"要有"，这里管"先比喻后术语的文风次序"。
5. **去权威、带自嘲温度（不端着）。** 主持人像邻居妈妈，不专家说教。"植物她也不懂数学啊""妈妈自己也没搞懂""普娃也能学得还可以"——有克制的自嘲与轻松调侃，传递"我也在看、在想"，而非"我来教你"。
6. **短句为主、密度克制、留白足。** 大多 10–20 字，几乎无长难句；信息不堆，每段留呼吸。密度高到听众跟不上即为失败。
7. **金句从对话长出，不是标语。** "数学的尊严在证对，不在填对""把奇迹，交给亲子互动时光"——都从对话里自然长出来，不是硬塞口号、不喊"时代变了"式结论句、不用感叹号标题。

### 4.2 对谈体「你」的处理纪律（反复翻车点）

本 IP 铁律禁「对听众的第二人称指认」，但**播客是双人对谈**，主持人 / 嘉宾互称"你"是角色间对话，不算违规。须分清两类：

- ✅ 角色间"你"（主持对小雅："你回家可以拿积木陪孩子玩""你只要会迈一步"）——双人对谈正常称谓，**保留，不得误删**。
- ❌ 面向听众的泛指"你"（"你一定会发现""你想想看"式对屏幕外听众喊话）——属违规指认，**改「咱们 / 家长」**。
- 判别法：把"你"换成具体对话对象（小雅 / 嘉宾）读着顺，就是角色间；换成听众读着像被点名，就是泛指，要改。

### 4.3 AI 写播客反复翻车清单（写前对照）

- ✗ 把策划清单体直接展开成念稿体 / 播报腔。
- ✗ 先抛术语定义、用"我们来认识 X"开场。
- ✗ 金句写成标语、结尾喊口号或点名"各位 / 小雅一句话"。
- ✗ 长难句堆叠、信息密度过高、无留白。
- ✗ 把对谈体角色间"你"当违规全部删除（破坏对谈感）。
- ✗ 用弱智设问（"你知道 X 吗？""X 重不重要？"）硬抛概念。

## 五、验收红线

1. 三栏等高、中间栏 ≤ 1/3（坚决不 1/2）。
2. 底栏 = 三栏之一 = 全屏 1/3，大字体台词铺满。
3. 主文字非纯白，深底配暖色点睛的哑光生活杂志风。
4. 非真人出镜、无卡通人物形象。
5. 演示面板仅中栏内、≤ 栏内一半、平时收起。
6. 配色：暖深炭 / 暖象牙 / 赭石金 / 朱砂，朱砂只一处。
7. 台词双人对谈、起范儿开场、闭环收尾。
8. 选题任意主题，内容讲透（定义 + 隐喻），无教知识腔。

## 六、制作备注

- 配音实测时长驱动时间轴。
- 分层混音：台词最大、BGM 最小（参考比例 台词增益 > BGM 增益数倍）。
- **逐轮 TTS + 实测时间戳字幕（2026-09-01 实证纪律）**：双人对谈逐轮合成（每轮独立音频 + ffprobe 实测时长），字幕时间戳用实测值——**禁止按字数比例估算**（TTS 语速不均，必漂移，用户可听出）。轮间气口 0.38s、轮内分块 0.12s；拼接用 PCM 层（wave 模块）或 filter_complex，**concat demuxer 混编 wav/mp3 会静默丢静音**。整轨完成后 silencedetect 比对验证（恒定偏移 ≤0.2s 合格）。
- **语速校正**：TTS 自然语速偏慢时用 atempo 全局校正（1.08x 实测自然），音画同步不破坏；章节时间轴按校正后时长重算。
- **BGM 纪律（宁空勿噪）**：只允许有节拍/旋律/和声的短衰减音色音乐（拨弦、马林巴类）；**持续长音 pad = 嗡嗡声，一刀禁绝**。音量 9-13%，首尾淡入淡出 3-6s。
- **确定性渲染**：三栏舞台所有画面状态（卡片淡入淡出、声波线）必须是时间 T 的纯函数——「逐帧向目标收敛」式动画在逐帧渲染下会卡死中间值（叠影实证）。
- **时长实证**：4,000 字逐轮合成 + 气口 ≈ 13 分钟；需要压短用 atempo 全局校正，勿删内容。
- 生产线完整经验见《视频生产线_经验得失_v1》。
- **配音验收必须测实际音量**：`ffmpeg -i 成片.mp4 -af volumedetect -f null -`。
  **有音轨 ≠ 有声音**——静音轨（−91 dB）照样带音轨，只看「有没有音轨」会漏检。
  分段渲染的长片尤须**逐段测**，末段最容易丢配音（本 IP 曾整片后段静音而未察觉）。
