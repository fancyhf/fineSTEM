# 儿童视频 · 制作规范

> 适用范围：本 IP 所有「儿童视频」——横屏、绘本风、成片、讲给孩子看（2–3 分钟）。
> 独立自包含，后续制作只读此一篇。
> 不绑定具体主题：通识教养 / STEM&AI / 多元升学 任一主题都按此标准。文中「[主题]」代表当集具体启蒙主题。

## 一、定位与边界

- 受众：孩子（低龄）。
- 启蒙 ≠ 教知识：讲思维本身 / 讲「怎么长」，不是刷题、不是重讲课本、不是名词砸脸。
- 与儿童 web 区分：儿童视频是成片（不可交互）；儿童 web 是可交互的网页动画。两者内核一致（启蒙），但载体不同，各自独立制作。
- 与成人内容（口播 / 家长播客）区分：成人内容不进儿童片；给大人听的叙事（讲解示范、双人对谈）一律不进儿童片。

## 二、策划规范

- 时长 2–3 分钟，围绕一个启蒙主题。
- 四问结构（域无关，通识教养 / STEM&AI / 多元升学 任一主题都覆盖核心）：
  1. 从一个具体可感的现象 / 例子切入（不先抛定义、不先砸名词）。
  2. 它怎么来的——人是怎么发现或想到它的（真实的探索过程，不是宣布结论）。
  3. 知道它有什么用——能做什么、和孩子生活或更大的世界有什么关联。
  4. 用一个具体例子让孩子自己「哦」出来（例子只是例子，不是主旨）。
- 落点永远是「思维 / 怎么想」（如「把前面的合起来定出下一个」「一个字怎么变成另一个字」），不是「名词 / 它叫什么」。

## 三、画面规范（横屏绘本风 + 五维构造法）

> ⚠️ **本节只规范视频内画面**。封面是平台物料（抖音 / 小红书 / 视频号），其尺寸、配色、版式、字号均**不套用本节**——封面按封面自身的标准执行。

- 横屏 16:9（成片 1920×1080）。
- 哑光米白绘本风：米白纸底 + 墨线 + 朱砂 / 赭石点缀；内核「看见怎么长」。
- 朱砂只点睛：同屏只一处红。
- 留白 ≥ 55%，单帧文字少、字号大。
- 动效必须：元素须「动」（长出弹跳、随机眨眼、答案定格），禁静态数据图。
- 五维构造法（缺一则像课件 PPT）：
  1. 外框：开放上沿 + 开放两侧，只留底边单线 + 四角云纹。
  2. 远景层：真实柔和色（云暖白 + 淡蓝灰描边、远山淡青低饱和、草竹绿），禁墨色剪影灰团。
  3. 标题区：左吉祥物（圆胖 + 表情 + 浮动，禁伸出撞远景）+ 中标题 + 右进度圆点（按内容段数亮）。
  4. 演示区辅助 UI：左贴士卡（三角指向主体）+ 右惊喜气泡 + 地平线草石；装饰 `pointer-events:none`。
  5. 底栏对话气泡：漫画式双层三角 + 圆胖按钮，承载逐句台词（与配音同步）。
- 角色 / 主角必须有脸：圆胖造型 + 中国色 + 墨线表情 + 不同内容不同表情。

## 四、台词规范（对孩子说的、孩子能懂）

- 台词是对孩子说的、孩子能懂的；儿童片台词必须是对孩子说的、孩子能懂的——不给大人听的叙事台词进儿童片。
- 启发式、反学习机：
  - 禁「小朋友们跟我读」「今天来认识 XX」「你真棒奖励星」「记住了吗再见」「名词砸脸（这是某某）」。
  - 从动作出发（点「长一座」塔自己长出）、提问邀请猜、规律让孩子自己「哦」出来。
  - 落点「它怎么长」非「它叫什么」；慢、留白、无口号、无「背」字命令。
- 对孩子认知真实：符合普遍理解力，不超龄归纳。

## 五、制作与验收

- 配音实测时长驱动时间轴（不靠帧估算）。
- 制作管线（逐句 TTS + 实测时间戳 + 确定性渲染）与工程坑见《视频生产线_经验得失_v1》。
- **配音验收必须测实际音量**：`ffmpeg -i 成片.mp4 -af volumedetect -f null -`。
  **有音轨 ≠ 有声音**——静音轨（−91 dB）照样带音轨，只看「有没有音轨」会漏检。
  分段渲染的片子尤须**逐段测**，末段最容易丢配音。
- 自测：启蒙非教知识？四问覆盖？五维构造齐？角色有脸？台词反学习机？动效有？配音实测有声？
