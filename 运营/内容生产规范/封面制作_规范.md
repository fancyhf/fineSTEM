# 封面制作 · 规范（抖音 / 小红书 / 视频号）

> 适用范围：本 IP 所有**平台封面**——发布到抖音、小红书、视频号用的封面图。
> 独立自包含，出封面只读此一篇，不引用其他文档。
> 不绑定视频类型：口播 / 家长播客 / 儿童视频 / 儿童 web 任一内容，都按此标准出封面。
> 不绑定主题：通识教养 / STEM&AI / 多元升学 任一主题都按此标准。文中「[主题]」代表当集具体内容。

---

## 〇、头条铁律：封面 ≠ 视频画面

- **封面是平台物料，不是视频内画面。** 两者的尺寸、配色、版式、字号逻辑**完全不同**。
- 本 IP 四类内容（口播 / 家长播客 / 儿童视频 / 儿童 web）的**视频内画面**各有其规范，
  **但那些规范一律不套用到封面**。拿画面规范做封面，做出来的会是「设计稿 / 大字报 / 海报」，
  不是平台上真会滑动到的封面。
- 封面的唯一任务：**在信息流里 0.5 秒内让人停下手指**。
- 成败判据一句话：**主体画面 + 文字叠加**。缺「画面主体」即失败
  —— 纯色渐变底 + 大字 = PPT 封面页，不是封面。

## 一、三平台硬参数

| | **抖音** | **小红书** | **视频号** |
|---|---|---|---|
| 推荐尺寸 | 1080×1920（9:16） | **1242×1660（3:4）** ← 首选 | 1080×1920（9:16） |
| 另需适配 | 个人主页以 **3:4** 显示 | 1:1 亦可用（占屏较小） | 信息流 3:4、分享 1:1 |
| 安全区 | 顶 220px / 底 380px | **底部 15%** | 标题放中上方 |
| 调性 | 有趣、直观、有价值 | 有人感、有场景、有利益点 | 温馨、实用、共鸣 |
| 主体 | 人 / 物 / 场景占 **70–80%** | 主体占 **60–70%** | 主体突出 |
| 文字 | ≤ 7–10 字，粗体无衬线 | 主标 3–10 字 + 副标 | 大字、信息别多 |
| 配色倾向 | 高对比撞色；浅色底被「吃掉」 | 高对比，拒绝大面积低饱和 | 与微信生态一致 |
| 平台坑 | **加边框 CTR 反降 12%** | **AI 生成图易被识别限流** | 营销感过重不利 |

**通则**：封面从视频帧选取或独立设计皆可；知识 / 口播类也可选 3:4（信息流展示面积更大）。

## 二、安全区（硬约束）

- 关键信息只放画面**中央 60–70%** 区域：上下各留约 15%、左右各留约 10% 作危险区。
- 竖版 9:16：顶部留 250px、底部留 350px（抖音实测顶 220 / 底 380）。
- 小红书 3:4：底部 **15%** 高度不放关键信息（会被标题与互动数据遮挡）。
- 不同展示位（信息流 / 主页 / 搜索）裁切比例不同，**主体一律居中**最稳。
- 出图后可用脚本自算内容 y 范围并 assert 校验，越界即重排。

## 三、封面模型（可复制，按内容选）

**模型 A · 数字冲击型**（知识科普流量最高）
超大数字 / 数据锚点 + 一句话解释它是什么
→「137.5°｜向日葵排种子的角度」

**模型 B · 特指问钩子型**（科普高频句式）
一个具体反直觉的问题 + 视觉主体
→「向日葵为什么按 137.5° 排种子？」

**模型 C · 反常识型**（CTR 高）
颠覆认知的陈述 + 主体画面
→「植物不懂数学，却把种子排得最省地方」

**模型 D · 场景 + 价值型**（亲子 / 教育向）
真实场景 + 受众能获得的明确价值
→「陪孩子数一次向日葵，递推思维就长出来了」

**模型 F · 教育类文字主体大字报**（2026-09-01 单词闯关项目实证，小红书教育赛道主流）

- **文字本身就是视觉主体，占版面 70% 以上**——不是场景插画配小字（「场景插画 + 对称小标题」版式被否，实证像 PPT 而非封面）
- 主标题 **3-7 字、全版最大字号**；全版 3-4 级字号层次，单一字体单一主色（多字体多色 = 杂）
- **浅底高对比**：奶油米白底 + 深墨大字是教育赛道主流；深底在信息流里沉
- **红笔手绘圈**圈住题眼关键词（手绘双笔道椭圆，勿用几何正圆）；关键词可加荧光笔色块
- **拼贴材质**让大字报不像 PPT：拍立得照片卡（白框+投影+胶带斜贴）、黄色便签（楷体手写感）、纸张颗粒与淡格线
- 干货清单用 ①②③ 序号（**emoji 在 PIL 字体里渲染为豆腐块**，一律不用）；底部留安全区

**模型 E · 红黑大字报型**（母婴赛道已验证爆款）
红黑大字 + 实物图 + 情绪词
→ 参考句式：「新生儿第 1 月最后悔的 10 件事」类

## 四、文案：句式库 + 避雷清单

### 可用句式
1. **数字 + 痛点 + 解决**（知识 / 技巧 / 教程流量最高）：「3 个方法，搞定孩子写作业拖拉」
2. **数字效率型**：「3 步搞定 XX」「5 分钟学会」「只用一招」
3. **提问式**：「孩子写作业拖拉怎么办？这 3 个方法亲测有效」
4. **反常识悬念**：「你以为的好习惯，其实正在害了你的孩子」
5. **避坑型**（母婴爆款）：「辅食添加别踩这 3 个坑」
6. **科普学术句式**：特指问（什么 / 为什么）｜是非问（是真的吗）｜「认识 / 解密 / 探秘 + 名词」｜「名词 + 的那些事」
   - 统计：科普标题 **52.8% 用比喻**，可适度采用

### 🚫 避雷清单（封面文案硬禁）
- **文艺长句**（如「这串数，哪儿都藏着」——播客 / 杂志语言，不是封面语言）
- **无情绪平淡文字**、模糊小字
- 堆三四行文字（信息一多用户直接划走）
- 与内容不符的标题党（高跳出率会触发算法降权）

### IP 铁律在封面的适用
- 禁**第二人称「你 / 你的孩子」指认** → 改用「家长 / 妈妈 / 爸妈 / 孩子」
- 禁**问号标题、感叹号标题**
- 禁**焦虑营销词**（破防 / 逆袭 / 捡漏 / 性价比 / 内卷 等）
- 禁**运营黑话**、禁**结论金句 / 标语**
- 禁**内部信息入封面**：内部策划、用户画像、项目口号一律不搬上封面
- 🔴 **臣对用户（AI 助手）的私域尊称，绝不出现在封面上**——那是内部称呼，不是对外的主播名 / 人设名。
  （节目嘉宾名如已在正片中公开使用，可跟随呈现；拿不准就**不放人名**。）
- **卖点判定**（亲子向内容尤须注意）：
  亲子内容的封面卖点是**「家长学会怎么跟孩子聊 / 日常寓教于乐」**，
  **不是学科本身**。数学、自然现象只是载体，退居副标或画面，不做主标题。

## 五、配色（知识类账号 A/B 实测三个月）

| 方案 | 主色 | 辅助色 | 平均 CTR | 完播 | 适用 |
|---|---|---|---|---|---|
| **A** | 深海蓝 `#0A2342` | 纯白 `#FFFFFF` | **8.4%** | 62% | 硬核科普、深度解读 ← 最稳 |
| B | 墨绿 `#1B4D3E` | 米黄 `#F5F5DC` | 7.9% | 58% | 自然生物、健康养生 |
| C | 紫 `#6A4C93` | 浅紫 `#E0D4FC` | 6.1% | 51% | 心理学、人文历史 |
| D | 亮橙 `#FF6B35` | 深灰 `#333333` | 5.2% | 45% | 辟谣、紧急提醒 |

**结论**：知识类用户偏好**保守安全**的视觉——深色 + 高亮字，比高饱和亮色 CTR 高 61%。
亲子 / 教育类可用暖米白底建立「温暖与信任」，但**文字必须深色**保证对比度。

## 六、排版硬规则

- 主标题字号约占画面 **1/5**（知识类主标 2–4 字最佳，副标小字补充）。
- **只放 1 个核心信息**，不堆多行。
- 布局：「左图右文」或「上图下文」——图 / 主体占核心，文字区留白。
- 强对比：深底浅字或浅底深字，**拒绝浅字浅底**。
- 主体占 60–80%，背景尽量简单，避免细碎纹理。
- 字号自适应（按目标宽度反算），不硬编码——避免溢出或过小。

## 七、技术坑清单（踩过的，逐条避开）

1. **中文字体缺全角标点**：思源宋体 Heavy 缺 `·`（U+00B7）`×`（U+00D7）`，`（U+FF0C）`、`（U+3001），
   渲染成豆腐块。**字体链：楷体 `simkai.ttf` → 思源宋体 Heavy → 微软雅黑**；默认用楷体。
2. **亮字压复杂画面必须描边**：`stroke_width=3~4` 黑色描边，否则亮字在画面亮暗交界处糊掉。
3. **深底上强调色用赭石金 `#C9A24B`，不用朱砂 `#C0392B`**——朱砂在深底上不跳；朱砂配米白底才跳。
4. **暗色蒙版 alpha 80–100（30–40%）**：平衡「保留画面感」与「文字可读」，压太死就没画面了。渐变蒙版优于均匀蒙版。
5. **小红书优先程序绘制 / 实拍，慎用 AI 生图**（平台识别后易限流）。
6. **有音轨 ≠ 有声音**：验收配音必须测实际音量（见下），静音轨（−91 dB）照样有音轨。
7. 竖版封面主体一律居中，兼容各展示位的裁切。
