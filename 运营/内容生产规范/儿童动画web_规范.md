# 儿童动画 web · 制作规范

> 适用范围：本 IP 所有「儿童动画 web」——可交互网页动画、讲给孩子看。
> 独立自包含，后续制作只读此一篇。
> 不绑定具体主题：通识教养 / STEM&AI / 多元升学 任一主题都按此标准。

## 一、定位与边界

- 受众：孩子（低龄），可交互。
- 与儿童视频同内核（启蒙、反学习机、讲「怎么长」），但载体是网页、可交互。
- 单文件自包含：HTML + CSS + JS + 字体 + 素材全内联，一个 .html 可直接打开运行。

## 二、策划规范

- 启蒙原则同儿童视频：四问结构、落点思维非名词、反学习机。
- 交互节点：在关键处设可点 / 可拖的交互，让孩子自己把它做出来、探索出来，非被动看。

## 三、画面规范

> ⚠️ **本节只规范视频内画面**。封面是平台物料（抖音 / 小红书 / 视频号），其尺寸、配色、版式、字号均**不套用本节**——封面按封面自身的标准执行。

- 横屏五维构造法（同儿童视频）：外框开放 / 远景真实柔色 / 标题区吉祥物 + 进度点 / 演示辅助 UI / 底栏对话气泡。
- 哑光米白绘本风，朱砂只点睛，留白 ≥ 55%，动效必须，角色有脸。

## 四、工程规范（web 专属，踩坑必守）

- 字体：中文字体必须内联（base64 / @font-face 内嵌 woff2），防方框。
- 层叠：绝对定位浮层须显式 `z-index`（浮层 ≥ 10），否则 DOM 后者盖前者。
- 复位：`resetState()` 真重置（清 DOM / 复位数据 / 进度点 / 气泡），不靠 `location.reload()`。
- 悬空元素（印章 / 标签）留 ≥ 自身尺寸 0.5 倍留白到他元素，否则视觉「压」在一起。
- 进度点绑单一数据源（如内容段数），不多处各算。
- frame 开放上沿 + 开放两侧、只留 border-bottom 收边；head 容器保持透明让远景显示，标题自身加纸底防反差不足。
- layout 撑高按内含内容反算，不纯靠 min-height。
- 单文件：所有资源 base64 内联，无外部依赖。

## 五、台词规范

- 同儿童视频：对孩子说的、孩子能懂；启发式反学习机；从动作出发、提问邀请猜；落点「怎么长」非「叫什么」。

## 六、制作与验收

- 浏览器实测交互（点得到、复位真清、无方框、无遮挡）。
- 自测：单文件可独立打开？五维构造齐？交互真可玩？台词反学习机？
