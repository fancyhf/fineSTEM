新增学习标准：[学习目标、复刻改造与助教执行规范](09_学习目标_复刻改造与助教执行规范.md)。每个sample须同时覆盖编程与算法、项目管理、领域知识、全过程docs和成果汇报；支持人类助教或AI agent引导孩子先理解式复刻，再自主改造。

**一个主题 sample = 一件可玩的作品 + 一套领域知识内容 + 一条自助创作路径 + 一份完整过程档案 + 家长视频与博客。**

当前只做可在浏览器中独立探索、制作与交付的线上作品。孩子按自己的节奏参与，不依赖硬件、实体材料、线下调查、教师授课或团队协作。家长内容帮助理解与交流，不作为孩子完成项目的必要条件。

## 首轮建议

1. 用“排队侦探”做一次完整 PBL 试点，检验开题、编码、证据、报告是否连贯。
2. 将现有“递推之美”转成“楼梯路线设计师”，验证旧内容如何变成项目入口。
3. 将“AI 说话之谜”转成“文字接龙实验室”，验证 AI 素养方向。

一个项目的最低交付：**可运行作品 + 开题卡 + 设计说明 + 数据/实验记录 + 调试与迭代记录 + 研究短文 + 学生自己的讲解**。首轮先完成一个案例，再扩项目库；12 个候选题不等于同时制作 12 套课程。

## 本次完成与边界

本次产出的是项目、课程、运营和产品优化的系统策划。示例中的测试数据均明确标为合成数据；没有真实学员成绩、试课结果或研究结论。代码能力与文档现状依据本地源码检查，未做生产环境端到端验证。现有业务代码、Know 已发布节目和另一目录中的原策划未改动。
